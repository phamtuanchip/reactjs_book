# Learn ReactJS From Absolute Zero: A Free Vietnamese Book From HTML to Next.js

*25 chapters that start before React — with the web, HTML, CSS and JavaScript — and end with a complete final project.*

Many React tutorials skip the foundations and leave beginners stuck the first time something breaks. This book assumes **no prior programming knowledge**: it teaches how the web works, HTML, CSS and modern JavaScript first, and only then React. **It is written in Vietnamese today; an English edition is planned.**

## Who it is for

- Complete beginners who want to become frontend developers
- Learners who don't yet understand SPAs, SSR, or how JavaScript handles state and memory
- Anyone who tried React before and hit a wall because the JavaScript wasn't solid

## What is inside

- **Part 1 — Web foundations (ch. 1–3):** how the web works, HTML, CSS
- **Part 2 — JavaScript (ch. 4–8):** basics, functions and scope, objects and arrays, asynchronous programming, ES6+
- **Part 3 — React basics (ch. 9–14):** what React is, JSX and components, state and events, `useEffect` and lifecycle, styling, React Router
- **Part 4 — Advanced React (ch. 15–20):** advanced hooks, global state, data fetching, forms, performance optimisation, testing
- **Part 5 — Ecosystem and practice (ch. 21–25):** TypeScript with React, Next.js, authentication and authorisation, deployment, and a complete capstone project

Each chapter includes examples in the repository and exercises to check your understanding.
