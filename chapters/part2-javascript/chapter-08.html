JavaScript Hiện đại (ES6+)

ES6 (ECMAScript 2015) và các phiên bản sau đã cách mạng hóa cách viết JavaScript. Chương này tổng hợp các tính năng hiện đại quan trọng nhất mà bạn sẽ dùng hàng ngày trong React, đồng thời giới thiệu TypeScript.

8.1 Template Literals

Template literals dùng backtick (`` ` ``) thay dấu nháy, cho phép nhúng biểu thức và viết chuỗi nhiều dòng.

const name = "An";
const age = 25;

// Cũ: nối chuỗi bằng +
const greeting1 = "Xin chào, " + name + "! Bạn " + age + " tuổi.";

// Mới: Template literal
const greeting2 = `Xin chào, ${name}! Bạn ${age} tuổi.`;

// Biểu thức phức tạp
const price = 15000000;
const msg = `Giá: ${price.toLocaleString('vi-VN')}đ (${price > 10000000 ? 'cao cấp' : 'tầm trung'})`;

// Chuỗi nhiều dòng
const html = `
  <div class="card">
    <h2>${name}</h2>
    <p>Tuổi: ${age}</p>
  </div>
`;

// Tagged template literals (nâng cao)
function highlight(strings, ...values) {
  return strings.reduce((result, str, i) =>
    result + str + (values[i] ? `<strong>${values[i]}</strong>` : ''), '');
}
const result = highlight`Tên: ${name}, Tuổi: ${age}`;
// "Tên: <strong>An</strong>, Tuổi: <strong>25</strong>"
// (Styled-components dùng kỹ thuật này!)

8.2 Modules — Import và Export

Modules cho phép chia code thành nhiều file riêng biệt, tái sử dụng và dễ bảo trì. Đây là nền tảng của mọi dự án React.

// === utils.js ===
// Named export — có thể export nhiều thứ
export const PI = 3.14159;

export function add(a, b) {
  return a + b;
}

export const multiply = (a, b) => a * b;

// Export class
export class Calculator {
  add(a, b) { return a + b; }
}

// Default export — mỗi file chỉ có 1
export default function subtract(a, b) {
  return a - b;
}

// === main.js ===
// Import named exports
import { PI, add, multiply } from './utils.js';

// Import với alias
import { multiply as mul } from './utils.js';

// Import default
import subtract from './utils.js';

// Import tất cả
import * as utils from './utils.js';
utils.add(1, 2);

// Import cả default và named
import subtract, { add, PI } from './utils.js';

// === Trong React ===
// Component files thường dùng default export
// utils/hooks dùng named export

// Button.jsx
export default function Button({ children, onClick }) {
  return <button onClick={onClick}>{children}</button>;
}

// hooks/useFetch.js
export function useFetch(url) { /* ... */ }
export function useLocalStorage(key) { /* ... */ }

// App.jsx
import Button from './Button';       // default
import { useFetch } from './hooks/useFetch'; // named

8.3 Optional Chaining và Nullish Coalescing

Hai tính năng ES2020 này giải quyết vấn đề truy cập dữ liệu lồng nhau có thể null/undefined — rất phổ biến khi làm việc với API.

// === Optional Chaining (?.) ===
const user = {
  name: "An",
  address: {
    city: "Hà Nội"
  }
};

// Cũ: kiểm tra từng cấp
const city1 = user && user.address && user.address.city;

// Mới: optional chaining
const city2 = user?.address?.city;  // "Hà Nội"

// Nếu user là null/undefined → trả về undefined (không throw lỗi)
const noUser = null;
noUser?.address?.city; // undefined (OK!)

// Với mảng
const arr = null;
arr?.[0];          // undefined

// Với method call
const obj = null;
obj?.toString();   // undefined
obj?.method?.();   // undefined

// Ví dụ thực tế (data từ API)
const response = await fetch('/api/user');
const data = await response.json();
const avatarUrl = data?.user?.profile?.avatar?.url ?? '/default-avatar.png';
// === Nullish Coalescing (??) ===
// Trả về vế phải nếu vế trái là null hoặc undefined
// Khác || ở chỗ: không coi 0, "" hay false là "falsy"

const count = 0;
count || 10;  // 10 (SAI! 0 là falsy)
count ?? 10;  // 0  (ĐÚNG! 0 không phải null/undefined)

const name = "";
name || "Anonymous"; // "Anonymous" (SAI nếu muốn giữ "")
name ?? "Anonymous"; // ""          (ĐÚNG!)

// Ví dụ thực tế
function displayCount(count) {
  const display = count ?? 0; // Nếu count là null/undefined → dùng 0
  return `Có ${display} sản phẩm`;
}
displayCount(null);      // "Có 0 sản phẩm"
displayCount(undefined); // "Có 0 sản phẩm"
displayCount(0);         // "Có 0 sản phẩm" (đúng!)
displayCount(5);         // "Có 5 sản phẩm"

// Nullish Assignment (??=)
let config = { timeout: null };
config.timeout ??= 5000; // Gán 5000 nếu timeout là null/undefined
// { timeout: 5000 }

8.4 Các tính năng ES6+ khác quan trọng

Class (ES6)

class Animal {
  #name; // Private field (ES2022)

  constructor(name, sound) {
    this.#name = name;
    this.sound = sound;
  }

  speak() {
    return `${this.#name} nói: ${this.sound}`;
  }

  // Static method — gọi trực tiếp trên class
  static create(name, sound) {
    return new Animal(name, sound);
  }

  // Getter/Setter
  get name() { return this.#name; }
  set name(value) {
    if (!value) throw new Error("Tên không được rỗng");
    this.#name = value;
  }
}

class Dog extends Animal {
  constructor(name) {
    super(name, "Gâu gâu"); // Gọi constructor cha
  }

  fetch(item) {
    return `${this.name} đi lấy ${item}!`;
  }
}

const dog = new Dog("Rex");
dog.speak(); // "Rex nói: Gâu gâu"
dog.fetch("bóng"); // "Rex đi lấy bóng!"

// Lưu ý: Trong React hiện đại, bạn dùng functional components
// Không cần class components nữa (nhưng cần hiểu để đọc code cũ)

Promise.all, Promise.allSettled, Promise.race

// Promise.all — chạy song song, chờ tất cả hoàn thành
// Nếu 1 promise fail → tất cả fail
const [users, posts, comments] = await Promise.all([
  fetch('/api/users').then(r => r.json()),
  fetch('/api/posts').then(r => r.json()),
  fetch('/api/comments').then(r => r.json()),
]);

// Promise.allSettled — chờ tất cả, không throw khi có lỗi
const results = await Promise.allSettled([
  fetch('/api/users'),
  fetch('/api/nonexistent'), // có thể fail
]);
results.forEach(r => {
  if (r.status === 'fulfilled') console.log(r.value);
  else console.log('Lỗi:', r.reason);
});

// Promise.race — lấy kết quả của promise hoàn thành ĐẦU TIÊN
const fastest = await Promise.race([
  fetch('/api/server1'),
  fetch('/api/server2'),
]);

// Promise.any — lấy kết quả ĐẦU TIÊN thành công (bỏ qua fail)
const firstSuccess = await Promise.any([
  fetch('/api/server1'), // có thể fail
  fetch('/api/server2'), // backup server
]);

Các tính năng nhỏ nhưng hữu ích

// Logical Assignment Operators (ES2021)
let a = null;
a ||= "default";  // a = a || "default" → "default"
a &&= a.toUpperCase(); // a = a && a.toUpperCase()
a ??= "fallback"; // a = a ?? "fallback"

// Array destructuring
const [first, second, ...rest] = [1, 2, 3, 4, 5];
// first=1, second=2, rest=[3,4,5]

// Swap biến
let x = 1, y = 2;
[x, y] = [y, x]; // x=2, y=1

// String methods mới
"  hello  ".trimStart();  // "hello  "
"  hello  ".trimEnd();    // "  hello"
"hello".padStart(8, "*"); // "***hello"
"hello".padEnd(8, "*");   // "hello***"
"ha".repeat(3);           // "hahaha"
"abc".replaceAll("a", "x"); // "xbc"

// Array methods mới
Array.from({ length: 5 }, (_, i) => i + 1); // [1, 2, 3, 4, 5]
[1, [2, [3, [4]]]].flat(Infinity); // [1, 2, 3, 4]
[1, 2, 3].at(-1);  // 3 (index âm)
[1, 2, 3].at(-2);  // 2

// Object.hasOwn (thay hasOwnProperty)
Object.hasOwn({ name: "An" }, "name"); // true

// globalThis — truy cập global object trong mọi môi trường
globalThis.setTimeout; // hoạt động trong browser và Node.js

8.5 Giới thiệu TypeScript

TypeScript là ngôn ngữ mở rộng của JavaScript, thêm vào hệ thống kiểu (type system) tĩnh. TypeScript compile xuống JavaScript thuần trước khi chạy.

Tại sao cần TypeScript?

// JavaScript — không có kiểu tĩnh
function add(a, b) {
  return a + b;
}
add(1, 2);        // 3 (đúng)
add("1", 2);      // "12" (sai! Không có lỗi nào)
add(1, "2");      // "12" (sai!)
add(true, false); // 1 (đúng về mặt kỹ thuật nhưng kỳ lạ)

// TypeScript — phát hiện lỗi ngay lúc viết code
function add(a: number, b: number): number {
  return a + b;
}
add(1, 2);        // OK
add("1", 2);      // ❌ Error: Argument of type 'string' is not assignable to parameter of type 'number'

TypeScript cơ bản

// Kiểu nguyên thủy
let name: string = "An";
let age: number = 25;
let active: boolean = true;
let nothing: null = null;
let undef: undefined = undefined;

// Mảng
let numbers: number[] = [1, 2, 3];
let names: Array<string> = ["An", "Bình"];

// Object type
let user: { name: string; age: number } = { name: "An", age: 25 };

// Interface — định nghĩa "hình dạng" của object
interface User {
  id: number;
  name: string;
  email: string;
  role?: string; // ? = optional (có thể không có)
  readonly createdAt: Date; // không thể thay đổi
}

// Type alias
type Point = { x: number; y: number };
type Status = "pending" | "active" | "inactive"; // Union type
type ID = string | number;

// Generic types
function identity<T>(arg: T): T {
  return arg;
}
identity<string>("hello"); // T = string
identity<number>(42);       // T = number

// TypeScript với React
interface ButtonProps {
  children: React.ReactNode;
  onClick: () => void;
  variant?: "primary" | "secondary";
  disabled?: boolean;
}

const Button = ({ children, onClick, variant = "primary", disabled = false }: ButtonProps) => {
  return <button onClick={onClick} className={variant} disabled={disabled}>{children}</button>;
};
💡 TypeScript trong dự án thực tế

Hầu hết dự án React hiện đại dùng TypeScript. Nó giúp: (1) Phát hiện bug sớm ngay khi gõ, (2) IDE autocomplete chính xác hơn, (3) Code dễ đọc và maintain, (4) Refactor an toàn. Chúng ta sẽ đi sâu vào TypeScript với React ở Chương 21.

Câu hỏi ôn bài

1. Sự khác biệt giữa ?? (nullish coalescing) và || (logical OR)?

  • A. Chúng hoàn toàn giống nhau
  • B. ?? chỉ trả về vế phải khi vế trái là null hoặc undefined, còn || coi cả 0, "", false là falsy
  • C. || nhanh hơn ??
  • D. ?? chỉ dùng được trong TypeScript

Đáp án: B — 0 ?? "default" trả về 0; 0 || "default" trả về "default". Dùng ?? khi muốn giữ các giá trị "falsy" hợp lệ như 0, "", false.

2. Kết quả của user?.profile?.avatar ?? '/default.png' khi user = { profile: null }?

  • A. Lỗi (TypeError)
  • B. null
  • C. '/default.png'
  • D. undefined

Đáp án: C — user?.profile?.avatar: user tồn tại, profile là null → null?.avatar → undefined. Sau đó undefined ?? '/default.png' → '/default.png'.

3. Mỗi file JavaScript/TypeScript có thể có bao nhiêu default export?

  • A. Không giới hạn
  • B. Tối đa 2
  • C. Chỉ 1
  • D. Không thể dùng default export

Đáp án: C — Mỗi module chỉ có thể có một default export, nhưng có thể có nhiều named exports. Khi import default, bạn có thể đặt bất kỳ tên nào.

4. TypeScript khác JavaScript ở điểm gì cơ bản nhất?

  • A. TypeScript chạy nhanh hơn JavaScript
  • B. TypeScript thêm hệ thống kiểu tĩnh, phát hiện lỗi khi viết code thay vì khi chạy
  • C. TypeScript là ngôn ngữ hoàn toàn khác, không liên quan đến JavaScript
  • D. TypeScript chỉ dành cho backend

Đáp án: B — TypeScript là superset của JavaScript: mọi JS hợp lệ đều là TS hợp lệ. TypeScript thêm type annotations, phát hiện lỗi lúc compile (trước khi chạy), sau đó compile xuống JavaScript thuần.

5. Kết quả của Promise.all([Promise.resolve(1), Promise.reject('lỗi'), Promise.resolve(3)])?

  • A. Trả về [1, 'lỗi', 3]
  • B. Bị reject với lý do 'lỗi'
  • C. Trả về [1, undefined, 3]
  • D. Bị reject với tất cả lỗi

Đáp án: B — Promise.all "fail fast": nếu bất kỳ promise nào bị reject, toàn bộ bị reject ngay lập tức. Dùng Promise.allSettled nếu muốn nhận kết quả của tất cả dù có lỗi.
