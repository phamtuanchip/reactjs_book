JavaScript Nhập môn

Làm quen với ngôn ngữ lập trình của web: từ biến, kiểu dữ liệu, toán tử đến điều kiện và vòng lặp.

4.1 JavaScript là gì?

Nếu HTML là bộ xương và CSS là bộ da của một trang web, thì JavaScript chính là "bộ não" — thứ làm cho trang web biết suy nghĩ, phản ứng và tương tác với người dùng.

JavaScript ra đời năm 1995, được Brendan Eich tạo ra trong vòng chỉ 10 ngày tại Netscape. Cái tên "JavaScript" thực ra là chiêu marketing — muốn bám vào sức hút của Java thời đó, dù hai ngôn ngữ này gần như không liên quan gì đến nhau. Tên chính thức theo tiêu chuẩn là ECMAScript (ES). Khi bạn nghe ES5, ES6, ES2020... đó đều là các phiên bản của JavaScript.

V8 engine là "trái tim" chạy JavaScript, được phát triển bởi Google. V8 biên dịch JavaScript thành mã máy (machine code) ngay lập tức thay vì thực thi từng dòng một — đây là lý do JavaScript ngày nay rất nhanh. Node.js cũng dùng chính V8 này, giúp JavaScript có thể chạy ngoài trình duyệt.

Ghi nhớ: Trong sách này, chúng ta học JavaScript để dùng trong trình duyệt và sau đó là React. Nhưng kiến thức nền tảng hoàn toàn áp dụng được cho Node.js sau này.

4.2 Cách nhúng JavaScript vào HTML

Có 3 cách để đưa JavaScript vào trang HTML. Mỗi cách có ưu và nhược điểm riêng.

Cách 1: Inline JavaScript (Viết trực tiếp trong thẻ HTML)

<!-- Inline JS trong attribute của thẻ -->
<button onclick="alert('Xin chào!')">Bấm vào đây</button>

<!-- Hoặc trong href -->
<a href="javascript:void(0)" onclick="doSomething()">Link</a>
Không khuyến khích! Inline JS trộn lẫn HTML và JavaScript, khó bảo trì và bảo mật kém. Chỉ dùng trong các ví dụ rất nhỏ.

Cách 2: Internal JavaScript (Thẻ <script> trong file HTML)

<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="UTF-8">
  <title>Trang web của tôi</title>
</head>
<body>
  <h1>Xin chào!</h1>

  <!-- Đặt script ở cuối body để HTML tải trước -->
  <script>
    console.log("JavaScript đang chạy!");
    alert("Chào mừng đến trang web của tôi!");
  </script>
</body>
</html>

Cách 3: External JavaScript (File .js riêng biệt) — Khuyến khích nhất

<!-- Trong file HTML -->
<!DOCTYPE html>
<html lang="vi">
<head>
  <meta charset="UTF-8">
  <title>Trang web của tôi</title>
</head>
<body>
  <h1>Xin chào!</h1>

  <!-- defer: tải JS song song nhưng chạy sau khi HTML xong -->
  <script src="script.js" defer></script>
</body>
</html>
// Trong file script.js
console.log("File JS bên ngoài đang chạy!");
document.querySelector('h1').textContent = "Đã được thay đổi bởi JS!";
Tại sao dùng external file?
Tái sử dụng được (nhiều trang HTML dùng chung 1 file JS), trình duyệt cache file JS nên load nhanh hơn, code sạch hơn và dễ bảo trì hơn.
Thuộc tính defer và async:
— defer: Tải JS song song với HTML, nhưng chạy sau khi HTML parse xong. Thứ tự thực thi giữ nguyên.
— async: Tải và chạy ngay khi tải xong, không quan tâm thứ tự. Dùng cho script độc lập (Google Analytics...).
— Không có attribute: Tải và chạy ngay lập tức, chặn việc render HTML. Tránh dùng!

4.4 Biến — Hộp chứa dữ liệu

Biến là "cái hộp" dùng để lưu trữ dữ liệu. JavaScript có 3 từ khóa để khai báo biến: var, let, và const.

var — Cách cũ (tránh dùng)

// var có function scope, không phải block scope
// var bị hoisting (đẩy lên đầu hàm)

function vidu() {
  if (true) {
    var x = 10;  // khai báo bên trong block
  }
  console.log(x);  // 10 — var "thoát" ra khỏi block!
}

// var cho phép khai báo lại (dễ gây bug)
var name = "An";
var name = "Bình";  // Không báo lỗi — nguy hiểm!
console.log(name);  // "Bình"

// Hoisting với var
console.log(y);  // undefined (không báo lỗi!)
var y = 5;
// Thực ra JS đã "hiểu" như thế này:
// var y;           // được đưa lên đầu (hoisted)
// console.log(y);  // undefined
// y = 5;

let — Khai báo biến có thể thay đổi

// let có block scope
if (true) {
  let a = 10;
  console.log(a);  // 10 — OK
}
// console.log(a);  // ReferenceError: a is not defined

// let không cho phép khai báo lại trong cùng scope
let name = "An";
// let name = "Bình";  // SyntaxError!

// Nhưng có thể reassign (gán lại giá trị)
let score = 8.5;
score = 9.0;  // OK
console.log(score);  // 9.0

// let KHÔNG bị hoisting như var
// console.log(b);  // ReferenceError
let b = 5;

const — Khai báo hằng số (không thể gán lại)

// const không thể gán lại sau khi khởi tạo
const PI = 3.14159;
// PI = 3;  // TypeError: Assignment to constant variable

// const phải được khởi tạo ngay lúc khai báo
// const MAX;  // SyntaxError!
const MAX = 100;  // OK

// QUAN TRỌNG: const với object/array chỉ khóa "reference"
// Không khóa nội dung bên trong!
const nguoi = { ten: "An", tuoi: 20 };
nguoi.tuoi = 21;       // OK — thay đổi property bên trong
console.log(nguoi);    // { ten: "An", tuoi: 21 }

const mang = [1, 2, 3];
mang.push(4);          // OK — thêm phần tử
console.log(mang);     // [1, 2, 3, 4]

// Nhưng không thể gán lại cả object/array
// nguoi = { ten: "Bình" };  // TypeError!

4.5 Kiểu dữ liệu

JavaScript có 7 kiểu dữ liệu primitive và 2 kiểu phức hợp (object, array).

Kiểu dữ liệu Primitive (Nguyên thủy)

1. String (Chuỗi ký tự)

const ten = "Nguyễn Văn An";     // Dùng dấu nháy đôi
const diaChi = 'Hà Nội';          // Dấu nháy đơn — cũng được
const loi_chao = `Xin chào, ${ten}!`;  // Template literal (ES6) — khuyến khích

console.log(typeof ten);  // "string"
console.log(loi_chao);   // "Xin chào, Nguyễn Văn An!"

2. Number (Số)

const tuoi = 25;           // Số nguyên
const chieu_cao = 1.75;    // Số thực
const am = -10;            // Số âm
const lon = 1e6;           // 1,000,000 (ký hiệu khoa học)

// Các giá trị đặc biệt
console.log(1 / 0);        // Infinity
console.log(-1 / 0);       // -Infinity
console.log(0 / 0);        // NaN (Not a Number)
console.log("abc" * 2);    // NaN

console.log(typeof tuoi);  // "number"
console.log(typeof NaN);   // "number" — ngạc nhiên chưa!

3. Boolean (Đúng/Sai)

const daDangNhap = true;
const laNguoiLon = false;

console.log(typeof daDangNhap);  // "boolean"

// Boolean thường xuất hiện trong các phép so sánh
console.log(5 > 3);   // true
console.log(5 < 3);   // false
console.log(5 === 5); // true

4. null — Có chủ đích không có giá trị

// null nghĩa là "không có giá trị" — được đặt CỐ TÌNH
let thongTinNguoiDung = null;  // Chưa có dữ liệu

console.log(thongTinNguoiDung);     // null
console.log(typeof null);            // "object" — đây là bug nổi tiếng của JS!
                                     // Thực ra null là primitive, không phải object

5. undefined — Chưa được khởi tạo

// undefined là giá trị mặc định của biến chưa được gán
let diemThi;
console.log(diemThi);  // undefined

// Hàm không có return cũng trả về undefined
function khongTraVe() {}
console.log(khongTraVe());  // undefined

// Sự khác biệt giữa null và undefined:
// null   = "Tôi biết biến này, nhưng nó đang trống"

console.log(null == undefined);   // true  (dùng == thì bằng nhau)
console.log(null === undefined);  // false (dùng === thì khác nhau)

6. Symbol (ES6) — Giá trị duy nhất

// Symbol tạo ra một giá trị duy nhất, không bao giờ trùng

console.log(id1 === id2);  // false — Dù cùng mô tả nhưng khác nhau!

// Symbol thường dùng làm key của object để tránh xung đột tên
const KEY = Symbol("secretKey");

// Number thông thường chỉ chính xác đến 2^53 - 1
console.log(Number.MAX_SAFE_INTEGER);  // 9007199254740991

// BigInt cho số nguyên lớn hơn
const soLon = 9007199254740991n;  // Thêm "n" ở cuối

Kiểu dữ liệu phức hợp

Object — Tập hợp cặp key:value

4.7 Toán tử

Toán tử số học

let a = 10;
let b = 3;

console.log(a + b);   // 13  — Cộng
console.log(a - b);   // 7   — Trừ
console.log(a * b);   // 30  — Nhân
console.log(a / b);   // 3.3333...  — Chia
console.log(a % b);   // 1   — Chia lấy dư (modulo)
console.log(a ** b);  // 1000 — Lũy thừa (10^3)

// Tăng / Giảm
let x = 5;
x++;   // x = 6 (tương đương x = x + 1)
x--;   // x = 5
++x;   // x = 6 (khác biệt với x++ khi dùng trong expression)

// Cộng chuỗi — Cẩn thận!
console.log("5" + 3);    // "53" — Nối chuỗi, không phải cộng số!
console.log(5 + 3);      // 8
console.log("5" - 3);    // 2   — Trừ ép kiểu về number
console.log("5" * "2");  // 10  — Nhân ép kiểu về number

Toán tử so sánh

console.log(5 > 3);    // true  — Lớn hơn
console.log(5 < 3);    // false — Nhỏ hơn
console.log(5 >= 5);   // true  — Lớn hơn hoặc bằng
console.log(5 <= 4);   // false — Nhỏ hơn hoặc bằng
console.log(5 == "5"); // true  — Bằng (KHÔNG kiểm tra kiểu — ép kiểu)
console.log(5 === "5");// false — Bằng nghiêm ngặt (kiểm tra cả kiểu)
console.log(5 != "5"); // false — Khác (không kiểm tra kiểu)
console.log(5 !== "5");// true  — Khác nghiêm ngặt

Tại sao nên dùng === thay vì ==?

Type coercion (ép kiểu ngầm) là khi JavaScript tự động chuyển đổi kiểu dữ liệu để so sánh. Điều này gây ra nhiều bug khó tìm: 

// == gây ra những kết quả khó đoán
console.log(0 == false);     // true  ← Sao lại thế?
console.log("" == false);    // true  ← ???
console.log(null == undefined); // true
console.log(1 == "1");       // true
console.log(1 == true);      // true
console.log(0 == "");        // true

// === không ép kiểu — luôn an toàn và rõ ràng
console.log(0 === false);    // false — khác kiểu nên false
console.log("" === false);   // false
console.log(null === undefined); // false
console.log(1 === "1");      // false

// Quy tắc: LUÔN dùng === và !==
// Chỉ dùng == khi cố tình muốn kiểm tra cả null và undefined cùng lúc:
function kiemTraNull(value) {
  if (value == null) {  // true nếu value là null HOẶC undefined
    console.log("Không có giá trị");
  }
}

Toán tử logic

// && (AND) — Cả hai đều phải true
console.log(true && true);   // true
console.log(true && false);  // false
console.log(false && true);  // false

// || (OR) — Ít nhất một phải true
console.log(true || false);  // true
console.log(false || false); // false

// ! (NOT) — Phủ định
console.log(!true);   // false
console.log(!false);  // true

// Short-circuit evaluation — Rất quan trọng!
// && dừng khi gặp false đầu tiên
let a = null;
let result = a && a.ten;  // "null" — an toàn, không bị lỗi "Cannot read property"

// || dừng khi gặp true đầu tiên — dùng để đặt giá trị mặc định
let tenNguoiDung = null;
let tenHienThi = tenNguoiDung || "Khách";
console.log(tenHienThi);  // "Khách"

// Nullish coalescing ?? (ES2020) — Chỉ null/undefined mới dùng default
let diem = 0;
console.log(diem || 10);   // 10 ← Sai! 0 bị coi là falsy
console.log(diem ?? 10);   // 0  ← Đúng! Chỉ thay khi là null/undefined

Toán tử 3 ngôi (Ternary)

// Cú pháp: điều_kiện ? giá_trị_nếu_đúng : giá_trị_nếu_sai
const tuoi = 20;
const tinhTrang = tuoi >= 18 ? "Người lớn" : "Trẻ vị thành niên";
console.log(tinhTrang);  // "Người lớn"

// Tương đương với:
let tinhTrang2;
if (tuoi >= 18) {
  tinhTrang2 = "Người lớn";
} else {
  tinhTrang2 = "Trẻ vị thành niên";
}

// Có thể lồng nhau (nhưng tránh lạm dụng)
const diem = 8.5;
const xepLoai = diem >= 9 ? "Xuất sắc"
              : diem >= 8 ? "Giỏi"
              : diem >= 6.5 ? "Khá"
              : diem >= 5 ? "Trung bình"
              : "Yếu";

4.8 Xử lý Chuỗi (String)

Template Literal — Cách hiện đại

const ten = "An";
const tuoi = 20;

// Cách cũ — nối chuỗi bằng +
console.log("Tôi là " + ten + ", " + tuoi + " tuổi.");

// Cách mới — template literal (dùng backtick `)
console.log(`Tôi là ${ten}, ${tuoi} tuổi.`);

// Template literal cho phép biểu thức phức tạp
console.log(`2 + 2 = ${2 + 2}`);
console.log(`Tên viết hoa: ${ten.toUpperCase()}`);

// Multi-line string

Bài tập chương 4: Tính điểm và xếp loại học lực

Viết chương trình JavaScript nhận vào danh sách điểm của 5 môn học, tính điểm trung bình và xếp loại học lực theo thang điểm Bộ GD&ĐT Việt Nam.

Yêu cầu:

  • Tính điểm trung bình (làm tròn 2 chữ số thập phân)
  • Xếp loại: Xuất sắc (≥9.0), Giỏi (≥8.0), Khá (≥6.5), Trung bình (≥5.0), Yếu (<5.0)
  • Hiển thị điểm từng môn, điểm trung bình và xếp loại
  • Kiểm tra điểm liệt (môn nào < 3.5 thì không đạt dù TB cao)

Code tham khảo:

// ===== BÀI TẬP CHƯƠNG 4 =====
// Tính điểm trung bình và xếp loại học lực

// Dữ liệu điểm
const danhSachDiem = [
  { monHoc: "Toán",      diem: 8.5 },
  { monHoc: "Ngữ văn",   diem: 7.5 },
  { monHoc: "Tiếng Anh", diem: 9.0 },
  { monHoc: "Vật lý",    diem: 8.0 },
  { monHoc: "Hóa học",   diem: 6.5 },
];

// Hằng số xếp loại
const XEP_LOAI = {
  XUAT_SAC: { nguong: 9.0, nhan: "Xuất sắc",    ky_hieu: "A+" },
  GIOI:     { nguong: 8.0, nhan: "Giỏi",         ky_hieu: "A"  },
  KHA:      { nguong: 6.5, nhan: "Khá",           ky_hieu: "B"  },
  TRUNG_BINH: { nguong: 5.0, nhan: "Trung bình", ky_hieu: "C"  },
  YEU:      { nguong: 0,   nhan: "Yếu",           ky_hieu: "D"  },
};

const DIEM_LIET = 3.5;  // Dưới 3.5 là điểm liệt

// --- Bước 1: Tính tổng điểm ---
let tongDiem = 0;
let coMonLiet = false;
let monLiet = null;

for (const item of danhSachDiem) {
  tongDiem += item.diem;
  if (item.diem < DIEM_LIET) {
    coMonLiet = true;
    monLiet = item;
  }
}

// --- Bước 2: Tính điểm trung bình ---
const diemTB = Math.round((tongDiem / danhSachDiem.length) * 100) / 100;

// --- Bước 3: Xếp loại ---
function xepLoai(diemTrungBinh, biDiemLiet) {
  if (biDiemLiet) return "Không đạt (có môn điểm liệt)";

  if (diemTrungBinh >= XEP_LOAI.XUAT_SAC.nguong) return XEP_LOAI.XUAT_SAC.nhan;
  if (diemTrungBinh >= XEP_LOAI.GIOI.nguong)     return XEP_LOAI.GIOI.nhan;
  if (diemTrungBinh >= XEP_LOAI.KHA.nguong)       return XEP_LOAI.KHA.nhan;
  if (diemTrungBinh >= XEP_LOAI.TRUNG_BINH.nguong) return XEP_LOAI.TRUNG_BINH.nhan;
  return XEP_LOAI.YEU.nhan;
}

// --- Bước 4: Xuất kết quả ---
console.log("=".repeat(40));
console.log("       KẾT QUẢ HỌC TẬP");
console.log("=".repeat(40));

for (const item of danhSachDiem) {
  const kieu = item.diem >= DIEM_LIET ? "✓" : "✗ (LIỆT)";
  const diemHienThi = item.diem.toFixed(1).padStart(4);
  console.log(`${item.monHoc.padEnd(12)} ${diemHienThi}  ${kieu}`);
}

console.log("-".repeat(40));
console.log(`${"ĐIỂM TRUNG BÌNH".padEnd(12)} ${diemTB.toFixed(2).padStart(4)}`);

if (coMonLiet) {
  console.log(`\n⚠ Cảnh báo: ${monLiet.monHoc} bị điểm liệt (${monLiet.diem})`);
}

const ketQua = xepLoai(diemTB, coMonLiet);
console.log(`\nXẾP LOẠI: ${ketQua}`);
console.log("=".repeat(40));

/* Kết quả mẫu:
========================================
       KẾT QUẢ HỌC TẬP
========================================
Toán          8.5  ✓
Ngữ văn       7.5  ✓
Tiếng Anh     9.0  ✓
Vật lý        8.0  ✓
Hóa học       6.5  ✓
----------------------------------------
ĐIỂM TRUNG BÌNH  7.90
XẾP LOẠI: Khá
========================================
*/

  • Tìm môn có điểm cao nhất và thấp nhất

Ôn bài — 5 câu hỏi tự kiểm tra

Câu 1: Sự khác biệt chính giữa let và const là gì? const có nghĩa là giá trị không bao giờ thay đổi được không?

Xem đáp án

let cho phép gán lại giá trị, const thì không. Tuy nhiên, const với object/array chỉ khóa reference (địa chỉ bộ nhớ), không khóa nội dung bên trong. Vẫn có thể thêm/sửa property của object và push phần tử vào array được khai báo bằng const.

Câu 2: Kết quả của các phép so sánh sau là gì và tại sao?

console.log(0 == false);
console.log(0 === false);
console.log("" == false);
console.log(null == undefined);
Xem đáp án

0 == false: true — vì == ép kiểu, false thành 0.
0 === false: false — khác kiểu (number vs boolean).
"" == false: true — cả hai đều là falsy, được ép về 0.
null == undefined: true — đây là trường hợp đặc biệt trong spec JS.

Câu 3: Vòng lặp for...of và for...in khác nhau như thế nào? Khi nào dùng cái nào?

Xem đáp án

for...of duyệt qua values của iterable (mảng, chuỗi, Map, Set). Dùng khi cần giá trị từng phần tử.
for...in duyệt qua keys (tên thuộc tính) của object. Dùng khi cần key của object. Không nên dùng for...in với mảng vì sẽ duyệt cả thuộc tính trên prototype.

Câu 4: typeof null trả về gì? Tại sao đây được coi là bug của JavaScript?

Xem đáp án

typeof null trả về "object". Đây là bug từ phiên bản đầu tiên của JavaScript năm 1995. Trong JavaScript, các giá trị được biểu diễn bằng một tag bit, và null vô tình được gán cùng tag với object (000). Bug này không sửa được vì sẽ phá vỡ hàng triệu trang web đang dựa vào hành vi đó. Để kiểm tra null chính xác, dùng value === null.

Câu 5: Kết quả của đoạn code sau là gì? Giải thích hoisting.

console.log(x);
var x = 5;
console.log(x);
Xem đáp án

Dòng 1: undefined (không phải lỗi!). Dòng 3: 5.
Hoisting với var: JavaScript đưa khai báo var x lên đầu phạm vi (nhưng không đưa phép gán = 5). Nên ở dòng 1, x đã được khai báo nhưng chưa có giá trị — nên là undefined. Đây là lý do nên dùng let/const thay vì var.
