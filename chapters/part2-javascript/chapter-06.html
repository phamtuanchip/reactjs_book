Object và Array Nâng cao

Object và Array là hai cấu trúc dữ liệu quan trọng nhất trong JavaScript. Nắm vững destructuring, spread, và các array methods là nền tảng để làm việc hiệu quả với state và props trong React.

6.1 Object Nâng cao

Tạo và truy cập Object

// Tạo object
const user = {
  name: "Nguyễn An",
  age: 25,
  role: "developer",
  address: {           // Nested object
    city: "Hà Nội",
    district: "Cầu Giấy"
  },
  skills: ["HTML", "CSS", "JavaScript"] // Array trong object
};

// Truy cập: dot notation
user.name;           // "Nguyễn An"
user.address.city;   // "Hà Nội"

// Truy cập: bracket notation (khi key là biến hoặc có khoảng trắng)
const field = "name";
user[field];         // "Nguyễn An"
user["role"];        // "developer"

// Thêm / sửa / xóa property
user.email = "an@example.com"; // thêm
user.age = 26;                  // sửa
delete user.role;               // xóa

Shorthand Properties và Methods

const name = "An";
const age = 25;

// Cách cũ
const user1 = { name: name, age: age };

// Shorthand (ES6) — khi tên biến = tên key
const user2 = { name, age };

// Method shorthand
const calc = {
  value: 0,
  // Cách cũ
  add: function(n) { this.value += n; },
  // Shorthand
  subtract(n) { this.value -= n; },
  // Arrow (không có this)
  getDouble: () => calc.value * 2
};

// Computed property names
const key = "dynamicKey";
const obj = {
  [key]: "value",                    // { dynamicKey: "value" }
  [`${key}_2`]: "value2",            // { dynamicKey_2: "value2" }
  [Date.now()]: "timestamp-key"
};

Destructuring Object

Destructuring là cú pháp trích xuất giá trị từ object/array vào các biến riêng — rất phổ biến trong React.

const user = { name: "An", age: 25, role: "admin", city: "HCM" };

// Cách cũ
const name1 = user.name;
const age1 = user.age;

// Destructuring — gọn hơn nhiều
const { name, age } = user;

// Đổi tên biến
const { name: userName, role: userRole } = user;
console.log(userName); // "An"

// Giá trị mặc định
const { country = "Việt Nam", name: n } = user;
console.log(country); // "Việt Nam" (user không có property này)

// Bỏ qua một số property
const { name: n2, ...rest } = user;
// rest = { age: 25, role: "admin", city: "HCM" }

// Nested destructuring
const { address: { city, district } } = {
  address: { city: "Hà Nội", district: "Cầu Giấy" }
};

// Destructuring trong tham số hàm
function displayUser({ name, age, role = "user" }) {
  console.log(`${name} (${age}) - ${role}`);
}
displayUser(user);

Spread Operator với Object

const defaults = { theme: "light", lang: "vi", fontSize: 16 };
const userPrefs = { theme: "dark", fontSize: 18 };

// Merge objects (sau ghi đè trước)
const settings = { ...defaults, ...userPrefs };
// { theme: "dark", lang: "vi", fontSize: 18 }

// Clone object (shallow copy)
const original = { name: "An", scores: [90, 85, 78] };
const clone = { ...original };
clone.name = "Bình"; // không ảnh hưởng original
clone.scores.push(92); // ảnh hưởng! scores là reference

// Deep clone — dùng structuredClone (modern) hoặc JSON trick
const deepClone = structuredClone(original);
// Hoặc: JSON.parse(JSON.stringify(original))

// Cập nhật một phần object (pattern quan trọng trong React)
const state = { user: "An", count: 0, loading: false };
const newState = { ...state, count: state.count + 1 };
// { user: "An", count: 1, loading: false }

// Cập nhật nested
const profile = { name: "An", address: { city: "HN", zip: "10000" } };
const updatedProfile = {
  ...profile,
  address: { ...profile.address, city: "HCM" }
};

Object Methods hữu ích

const user = { name: "An", age: 25, role: "dev" };

// Object.keys() — lấy mảng các key
Object.keys(user);   // ["name", "age", "role"]

// Object.values() — lấy mảng các value
Object.values(user); // ["An", 25, "dev"]

// Object.entries() — lấy mảng các [key, value]
Object.entries(user); // [["name","An"], ["age",25], ["role","dev"]]

// Dùng với destructuring
for (const [key, value] of Object.entries(user)) {
  console.log(`${key}: ${value}`);
}

// Object.fromEntries() — chuyển từ entries về object
const entries = [["a", 1], ["b", 2]];
Object.fromEntries(entries); // { a: 1, b: 2 }

// Chuyển đổi object
const doubled = Object.fromEntries(
  Object.entries(user).map(([k, v]) =>
    [k, typeof v === "number" ? v * 2 : v]
  )
);

// Object.assign() — merge (tương đương spread)
const merged = Object.assign({}, defaults, userPrefs);

// Object.freeze() — không thể thay đổi object
const config = Object.freeze({ api: "https://api.example.com", version: 2 });
// config.api = "..."; // Silently fail (hoặc throw trong strict mode)

// Kiểm tra property
"name" in user;              // true
user.hasOwnProperty("name"); // true

6.2 Array Methods Nâng cao

Các array methods dưới đây là những gì bạn dùng hàng ngày trong React để render danh sách, lọc dữ liệu, và cập nhật state.

const products = [
  { id: 1, name: "Laptop", price: 15000000, category: "tech", inStock: true },
  { id: 2, name: "Áo sơ mi", price: 350000, category: "fashion", inStock: false },
  { id: 3, name: "Điện thoại", price: 8000000, category: "tech", inStock: true },
  { id: 4, name: "Quần jean", price: 450000, category: "fashion", inStock: true },
  { id: 5, name: "Tai nghe", price: 2500000, category: "tech", inStock: true },
];

// map — biến đổi mỗi phần tử
const names = products.map(p => p.name);
// ["Laptop", "Áo sơ mi", "Điện thoại", "Quần jean", "Tai nghe"]

const withDiscount = products.map(p => ({
  ...p,
  discountedPrice: p.price * 0.9
}));

// filter — lọc phần tử
const techProducts = products.filter(p => p.category === "tech");
const available = products.filter(p => p.inStock);
const expensive = products.filter(p => p.price > 1000000);

// find — tìm phần tử đầu tiên thỏa điều kiện
const laptop = products.find(p => p.name === "Laptop");
const firstTech = products.find(p => p.category === "tech");

// findIndex — tìm INDEX của phần tử đầu tiên
const laptopIndex = products.findIndex(p => p.id === 1); // 0

// some — có ÍT NHẤT 1 phần tử thỏa điều kiện?
const hasExpensive = products.some(p => p.price > 10000000); // true
const hasOutOfStock = products.some(p => !p.inStock);       // true

// every — TẤT CẢ phần tử thỏa điều kiện?
const allInStock = products.every(p => p.inStock); // false
const allAffordable = products.every(p => p.price < 20000000); // true

// reduce — gộp thành 1 giá trị
const totalValue = products.reduce((sum, p) => sum + p.price, 0);
// 26300000

// Nhóm theo category
const byCategory = products.reduce((groups, p) => {
  const category = p.category;
  return {
    ...groups,
    [category]: [...(groups[category] || []), p]
  };
}, {});
// { tech: [...], fashion: [...] }

// sort — sắp xếp (CẦN THẬN: sort thay đổi mảng gốc!)
const byPrice = [...products].sort((a, b) => a.price - b.price); // tăng dần
const byPriceDesc = [...products].sort((a, b) => b.price - a.price); // giảm dần
const byName = [...products].sort((a, b) => a.name.localeCompare(b.name));

// flat và flatMap
const nested = [[1, 2], [3, 4], [5]];
nested.flat(); // [1, 2, 3, 4, 5]

const sentences = ["Hello world", "React is great"];
sentences.flatMap(s => s.split(" ")); // ["Hello", "world", "React", "is", "great"]

Cập nhật Array không thay đổi (Immutable Updates)

Trong React, bạn KHÔNG được thay đổi state trực tiếp. Luôn tạo mảng mới:

const items = [1, 2, 3, 4, 5];

// Thêm phần tử vào cuối
const added = [...items, 6]; // [1, 2, 3, 4, 5, 6]

// Thêm vào đầu
const prepended = [0, ...items]; // [0, 1, 2, 3, 4, 5]

// Thêm vào vị trí bất kỳ (index 2)
const inserted = [...items.slice(0, 2), 99, ...items.slice(2)];
// [1, 2, 99, 3, 4, 5]

// Xóa phần tử (theo index)
const removed = items.filter((_, index) => index !== 2); // [1, 2, 4, 5]

// Xóa theo value
const removedValue = items.filter(item => item !== 3); // [1, 2, 4, 5]

// Cập nhật phần tử (theo index)
const updated = items.map((item, index) =>
  index === 2 ? item * 10 : item
); // [1, 2, 30, 4, 5]

// Cập nhật object trong array (theo id)
const todos = [
  { id: 1, text: "Học HTML", done: false },
  { id: 2, text: "Học CSS", done: false },
  { id: 3, text: "Học React", done: false },
];

const toggleTodo = (id) => todos.map(todo =>
  todo.id === id ? { ...todo, done: !todo.done } : todo
);

6.3 Immutability — Tại sao không thay đổi trực tiếp?

Immutability nghĩa là không thay đổi dữ liệu gốc mà luôn tạo bản sao mới. Đây là nguyên tắc cốt lõi trong React.

// VẤN ĐỀ: mutation trực tiếp
const state = { count: 0, items: [] };

// Sai — thay đổi object gốc
state.count = 1;  // React không biết state đã thay đổi!
state.items.push("item"); // Cũng sai!

// React so sánh tham chiếu (reference): state === newState
// Nếu cùng reference → không re-render → UI không cập nhật!

// Đúng — tạo object mới
const newState = { ...state, count: 1 };
// newState !== state → React biết cần re-render

// Đúng — tạo array mới
const newItems = [...state.items, "item"];

// Tại sao?
const arr = [1, 2, 3];
const arr2 = arr;        // arr2 và arr là CÙNG tham chiếu
arr.push(4);             // Thay đổi arr → arr2 cũng thay đổi!
console.log(arr2);       // [1, 2, 3, 4]

const arr3 = [...arr];   // arr3 là THAM CHIẾU MỚI
arr3.push(5);            // Không ảnh hưởng arr
console.log(arr);        // [1, 2, 3, 4]

6.4 JSON — Định dạng trao đổi dữ liệu

// JSON = JavaScript Object Notation
// Dùng để lưu và truyền dữ liệu (giữa client và server)

// JSON.stringify() — chuyển JavaScript → JSON string
const user = {
  name: "An",
  age: 25,
  skills: ["HTML", "React"],
  active: true
};
const jsonString = JSON.stringify(user);
// '{"name":"An","age":25,"skills":["HTML","React"],"active":true}'

// JSON.parse() — chuyển JSON string → JavaScript object
const parsed = JSON.parse(jsonString);
parsed.name; // "An"

// Lưu vào localStorage (chỉ lưu được string)
localStorage.setItem("user", JSON.stringify(user));
const savedUser = JSON.parse(localStorage.getItem("user"));

// JSON.stringify với indentation (để debug)
console.log(JSON.stringify(user, null, 2));
// {
//   "name": "An",
//   "age": 25,
//   ...
// }

// Giới hạn của JSON:
// - Không hỗ trợ: undefined, function, Symbol, Date (mất timezone)
// - Có circular reference → lỗi
const obj = { fn: () => "hello", undef: undefined };
JSON.stringify(obj); // "{}" — cả hai bị bỏ qua!

Câu hỏi ôn bài

1. Kết quả của đoạn code sau?

const { a, b = 10, ...rest } = { a: 1, c: 3, d: 4 };
console.log(a, b, rest);
  • A. 1 undefined { c: 3, d: 4 }
  • B. 1 10 { c: 3, d: 4 }
  • C. 1 10 { b: 10, c: 3, d: 4 }
  • D. Lỗi

Đáp án: B — a = 1 (từ object), b = 10 (default vì object không có b), rest = { c: 3, d: 4 } (phần còn lại sau khi lấy a và b).

2. Sự khác biệt giữa find() và filter()?

  • A. find() trả về mảng, filter() trả về phần tử đơn
  • B. find() trả về phần tử đầu tiên thỏa điều kiện, filter() trả về mảng tất cả phần tử thỏa điều kiện
  • C. Chúng hoàn toàn giống nhau
  • D. find() thay đổi mảng gốc

Đáp án: B — find() dừng lại khi tìm thấy phần tử đầu tiên và trả về phần tử đó (hoặc undefined). filter() duyệt toàn bộ mảng và trả về mảng mới chứa tất cả phần tử thỏa điều kiện.

3. Tại sao trong React, ta không nên gọi array.push() để cập nhật state?

  • A. push() quá chậm
  • B. push() thay đổi mảng gốc, React không phát hiện được thay đổi và không re-render
  • C. push() không hoạt động trong React
  • D. push() trả về undefined

Đáp án: B — React so sánh tham chiếu để phát hiện thay đổi. push() thay đổi array tại chỗ → tham chiếu không đổi → React không biết cần re-render. Dùng spread: setItems([...items, newItem]).

4. JSON.stringify({ fn: () => {}, val: undefined }) trả về gì?

  • A. '{"fn":"() => {}","val":"undefined"}'
  • B. Lỗi
  • C. '{}'
  • D. '{"fn":null,"val":null}'

Đáp án: C — '{}' — JSON không hỗ trợ functions và undefined. Các property này bị bỏ qua hoàn toàn khi stringify. null thì được hỗ trợ.

5. Cách nào đúng để cập nhật một trường trong object state của React?

  • A. state.name = "Mới";
  • B. setState(state.name = "Mới");
  • C. setState({ ...state, name: "Mới" });
  • D. setState(Object.assign(state, { name: "Mới" }));

Đáp án: C — Spread tạo object mới với tất cả property cũ, sau đó override name. A và B đều mutate trực tiếp. D dùng Object.assign mutate đối số đầu tiên (state gốc).
