CSS — Trang điểm cho trang web

CSS (Cascading Style Sheets) biến HTML thô thành giao diện đẹp, chuyên nghiệp. Từ màu sắc, font chữ đến layout phức tạp — CSS kiểm soát tất cả những gì bạn nhìn thấy.

3.1 CSS là gì? Cách liên kết với HTML

CSS (Cascading Style Sheets — Bảng biểu định kiểu theo tầng) là ngôn ngữ mô tả cách trình bày của tài liệu HTML. CSS tách biệt hoàn toàn giữa nội dung (HTML) và giao diện (CSS) — nguyên tắc quan trọng trong lập trình web.

3 cách liên kết CSS với HTML

<!-- 1. External CSS (khuyến nghị) — CSS trong file riêng -->
<head>
  <link rel="stylesheet" href="styles.css">
</head>

<!-- 2. Internal CSS — CSS trong thẻ <style> trong <head> -->
<head>
  <style>
    body { background: #f0f0f0; }
    h1 { color: navy; }
  </style>
</head>

<!-- 3. Inline CSS — CSS trực tiếp trên phần tử (tránh dùng) -->
<p style="color: red; font-size: 18px;">Đoạn văn màu đỏ</p>
💡 Tại sao External CSS là tốt nhất?

External CSS (link href) cho phép bạn: (1) Tái sử dụng một file CSS cho nhiều trang HTML, (2) Trình duyệt cache file CSS (tải trang nhanh hơn), (3) Tách biệt rõ ràng giữa cấu trúc và giao diện.

3.2 Selector, Property và Value

Cú pháp CSS gồm 3 phần:

/* Cú pháp cơ bản */
selector {
  property: value;
  property: value;
}

/* Ví dụ */
h1 {
  color: #61dafb;     /* màu chữ */
  font-size: 2rem;    /* cỡ chữ */
  font-weight: 700;   /* độ đậm */
  text-align: center; /* căn giữa */
}

Các loại Selector

/* === BASIC SELECTORS === */

/* Element selector — áp dụng cho tất cả thẻ h2 */
h2 { color: blue; }

/* Class selector — áp dụng cho phần tử có class="btn" */
.btn { padding: 10px 20px; }

/* ID selector — áp dụng cho phần tử có id="header" */
#header { background: #282c34; }

/* Universal selector — áp dụng cho tất cả phần tử */
* { box-sizing: border-box; }

/* === COMBINATOR SELECTORS === */

/* Descendant: tất cả <a> bên trong <nav> */
nav a { color: white; }

/* Child: chỉ <li> là con trực tiếp của <ul> */
ul > li { list-style: none; }

/* Adjacent sibling: <p> đứng ngay sau <h2> */
h2 + p { color: gray; }

/* === PSEUDO-CLASSES === */
a:hover { text-decoration: underline; }     /* khi hover */
a:active { opacity: 0.8; }                  /* khi click */
a:visited { color: purple; }                /* đã thăm */
input:focus { border-color: #61dafb; }      /* khi focus */
li:first-child { font-weight: bold; }       /* phần tử đầu */
li:last-child { border-bottom: none; }      /* phần tử cuối */
li:nth-child(2n) { background: #f5f5f5; }   /* chẵn */
p:not(.special) { color: gray; }            /* không có class */

/* === PSEUDO-ELEMENTS === */
p::first-line { font-weight: bold; }        /* dòng đầu */
p::first-letter { font-size: 2em; }         /* chữ đầu */
.btn::before { content: "→ "; }             /* thêm trước */
.btn::after { content: " ✓"; }              /* thêm sau */

/* === ATTRIBUTE SELECTORS === */
input[type="email"] { border: 2px solid blue; }
a[target="_blank"]::after { content: " ↗"; }
img[alt=""] { border: 3px solid red; }      /* ảnh thiếu alt! */

3.3 Box Model

Mọi phần tử HTML đều là một "hộp" (box). Box model mô tả không gian xung quanh phần tử đó:

graph TD subgraph MG["🔲 MARGIN — Khoảng cách bên ngoài"] subgraph BD["🟫 BORDER — Đường viền"] subgraph PD["🟨 PADDING — Đệm bên trong"] CT["📦 CONTENT width × height"] end end end style MG fill:#1e2127,stroke:#e06c75,color:#e06c75 style BD fill:#282c34,stroke:#e5c07b,color:#e5c07b style PD fill:#21252b,stroke:#98c379,color:#98c379 style CT fill:#2c313a,stroke:#61dafb,color:#61dafb 
.box {
  /* Content */
  width: 300px;
  height: 200px;

  /* Padding — khoảng cách bên TRONG border */
  padding: 20px;              /* tất cả 4 phía */
  padding: 10px 20px;         /* trên/dưới | trái/phải */
  padding: 10px 20px 15px 25px; /* trên | phải | dưới | trái */
  padding-top: 10px;

  /* Border — đường viền */
  border: 2px solid #61dafb;
  border-radius: 8px;         /* bo góc */
  border-top: 3px dashed red;

  /* Margin — khoảng cách bên NGOÀI border */
  margin: 16px;
  margin: 0 auto;             /* căn giữa theo chiều ngang */
  margin-bottom: 24px;
}

/* box-sizing: border-box — QUAN TRỌNG!
   Mặc định (content-box): width = content only
   border-box: width bao gồm cả padding và border */
* {
  box-sizing: border-box; /* Best practice — luôn thêm dòng này */
}
💡 box-sizing: border-box

Với content-box (mặc định): nếu bạn set width: 300px; padding: 20px; border: 2px solid, phần tử thực sự rộng 344px. Gây nhầm lẫn! Với border-box: tổng chiều rộng luôn là 300px — dễ tính toán hơn nhiều. Luôn đặt * { box-sizing: border-box; } ở đầu file CSS.

3.4 Flexbox — Layout 1 chiều

Flexbox (Flexible Box Layout) là công cụ mạnh mẽ để sắp xếp các phần tử theo một chiều (hàng hoặc cột). Đây là layout system bạn dùng nhiều nhất trong React.

/* Container (cha) */
.container {
  display: flex;

  /* Hướng sắp xếp */
  flex-direction: row;           /* → hàng (mặc định) */
  flex-direction: column;        /* ↓ cột */
  flex-direction: row-reverse;   /* ← hàng ngược */

  /* Căn chỉnh theo trục chính (main axis) */
  justify-content: flex-start;   /* dồn về đầu */
  justify-content: flex-end;     /* dồn về cuối */
  justify-content: center;       /* căn giữa */
  justify-content: space-between; /* cách đều, sát mép */
  justify-content: space-around;  /* cách đều với margin */
  justify-content: space-evenly;  /* cách đều hoàn toàn */

  /* Căn chỉnh theo trục phụ (cross axis) */
  align-items: stretch;          /* kéo dài (mặc định) */
  align-items: flex-start;       /* về đầu */
  align-items: flex-end;         /* về cuối */
  align-items: center;           /* căn giữa */
  align-items: baseline;         /* theo baseline chữ */

  /* Xuống dòng */
  flex-wrap: nowrap;             /* không xuống dòng (mặc định) */
  flex-wrap: wrap;               /* cho phép xuống dòng */

  /* Khoảng cách giữa các item */
  gap: 16px;                     /* khoảng cách đều */
  gap: 8px 16px;                 /* hàng | cột */
}

/* Item (con) */
.item {
  /* Phân chia không gian */
  flex-grow: 1;    /* chiếm không gian còn lại */
  flex-shrink: 0;  /* không co lại khi thiếu chỗ */
  flex-basis: 200px; /* kích thước cơ sở */
  flex: 1;         /* shorthand: flex-grow:1, shrink:1, basis:0 */
  flex: 0 0 200px; /* fixed 200px, không grow/shrink */

  /* Căn chỉnh riêng từng item */
  align-self: center;
  order: 2;        /* thứ tự hiển thị */
}

Ví dụ thực tế với Flexbox

/* Navigation bar */
.navbar {
  display: flex;
  justify-content: space-between;
  align-items: center;
  padding: 0 24px;
  height: 60px;
  background: #282c34;
}

/* Card grid */
.card-grid {
  display: flex;
  flex-wrap: wrap;
  gap: 24px;
}
.card {
  flex: 1 1 300px; /* co giãn, tối thiểu 300px */
  max-width: 400px;
}

/* Căn giữa một phần tử */
.centered {
  display: flex;
  justify-content: center;
  align-items: center;
  min-height: 100vh; /* full màn hình */
}

3.5 CSS Grid — Layout 2 chiều

CSS Grid dùng cho layout hai chiều (hàng và cột cùng lúc). Phù hợp hơn Flexbox khi cần layout dạng lưới phức tạp.

.grid-container {
  display: grid;

  /* Định nghĩa cột */
  grid-template-columns: 200px 1fr 1fr;     /* 3 cột */
  grid-template-columns: repeat(3, 1fr);     /* 3 cột bằng nhau */
  grid-template-columns: repeat(auto-fill, minmax(250px, 1fr)); /* responsive */

  /* Định nghĩa hàng */
  grid-template-rows: 60px 1fr auto;
  grid-auto-rows: minmax(100px, auto);      /* hàng tự động */

  /* Khoảng cách */
  gap: 16px;
  column-gap: 24px;
  row-gap: 16px;

  /* Areas (đặt tên vùng) */
  grid-template-areas:
    "header  header  header"
    "sidebar content content"
    "footer  footer  footer";
}

/* Đặt phần tử vào area */
.header  { grid-area: header; }
.sidebar { grid-area: sidebar; }
.content { grid-area: content; }
.footer  { grid-area: footer; }

/* Hoặc dùng line numbers */
.item {
  grid-column: 1 / 3;    /* từ line 1 đến line 3 (chiếm 2 cột) */
  grid-row: 2 / 4;       /* chiếm 2 hàng */
  grid-column: span 2;   /* hoặc: span 2 cột */
}

3.6 Responsive Design và Media Query

Responsive design là thiết kế giao diện thích nghi với mọi kích thước màn hình — từ điện thoại nhỏ đến màn hình desktop lớn.

/* Mobile First — viết CSS cho mobile trước, rồi thêm cho lớn hơn */

/* Mặc định (mobile): 1 cột */
.grid {
  display: grid;
  grid-template-columns: 1fr;
  gap: 16px;
}

/* Tablet (≥ 768px): 2 cột */
@media (min-width: 768px) {
  .grid {
    grid-template-columns: repeat(2, 1fr);
  }
}

/* Desktop (≥ 1024px): 3 cột */
@media (min-width: 1024px) {
  .grid {
    grid-template-columns: repeat(3, 1fr);
  }
}

/* Breakpoints phổ biến */
/* sm: 640px | md: 768px | lg: 1024px | xl: 1280px | 2xl: 1536px */
/* (đây cũng là breakpoints của Tailwind CSS) */

/* Media queries khác */
@media (prefers-color-scheme: dark) {
  body { background: #1a1a2e; color: white; }
}

@media print {
  .sidebar, .nav { display: none; }
}

@media (max-width: 767px) {
  /* Desktop-first: ẩn trên mobile */
  .desktop-only { display: none; }
}

/* Các phép đo thông dụng */
/* px: pixel tuyệt đối */
/* em: tương đối với font-size của phần tử cha */
/* rem: tương đối với font-size gốc (thường = 16px) */
/* %: tương đối với phần tử cha */
/* vw/vh: phần trăm viewport width/height */
/* fr: fraction (chỉ dùng trong Grid) */

3.7 CSS Variables (Custom Properties)

CSS Variables cho phép bạn định nghĩa các giá trị có thể tái sử dụng, dễ thay đổi toàn bộ theme.

/* Khai báo variables trong :root (global scope) */
:root {
  /* Màu sắc */
  --color-primary: #61dafb;
  --color-secondary: #282c34;
  --color-text: #abb2bf;
  --color-bg: #1e2127;

  /* Typography */
  --font-size-sm: 0.875rem;
  --font-size-base: 1rem;
  --font-size-lg: 1.125rem;
  --font-size-xl: 1.25rem;

  /* Spacing */
  --spacing-xs: 4px;
  --spacing-sm: 8px;
  --spacing-md: 16px;
  --spacing-lg: 24px;
  --spacing-xl: 48px;

  /* Border radius */
  --radius-sm: 4px;
  --radius-md: 8px;
  --radius-lg: 16px;
}

/* Sử dụng variables */
.button {
  background: var(--color-primary);
  color: var(--color-secondary);
  padding: var(--spacing-sm) var(--spacing-md);
  border-radius: var(--radius-md);
  font-size: var(--font-size-base);
}

/* Dark mode bằng variables */
@media (prefers-color-scheme: dark) {
  :root {
    --color-bg: #0d1117;
    --color-text: #c9d1d9;
  }
}

/* Override variables tại scope hẹp hơn */
.card {
  --spacing-md: 12px; /* Chỉ áp dụng trong .card */
  padding: var(--spacing-md);
}

3.8 Các kỹ thuật CSS quan trọng khác

Transitions và Animations

/* Transition — hiệu ứng chuyển đổi khi property thay đổi */
.button {
  background: #61dafb;
  transition: background 0.2s ease, transform 0.2s ease;
}
.button:hover {
  background: #21a1c4;
  transform: translateY(-2px);
}

/* Transition shorthand */
transition: all 0.3s ease-in-out;

/* Keyframe Animation */
@keyframes fadeIn {
  from { opacity: 0; transform: translateY(20px); }
  to   { opacity: 1; transform: translateY(0); }
}

.card {
  animation: fadeIn 0.4s ease forwards;
}

/* Spin animation cho loading spinner */
@keyframes spin {
  to { transform: rotate(360deg); }
}
.spinner {
  width: 40px; height: 40px;
  border: 4px solid rgba(97,218,251,0.2);
  border-top-color: #61dafb;
  border-radius: 50%;
  animation: spin 0.8s linear infinite;
}

Position

.element {
  position: static;    /* mặc định — theo flow thông thường */
  position: relative;  /* vẫn trong flow, nhưng có thể dùng top/left */
  position: absolute;  /* ra khỏi flow, relative với positioned ancestor */
  position: fixed;     /* relative với viewport, không scroll */
  position: sticky;    /* kết hợp relative và fixed */
}

/* Ví dụ: overlay */
.modal-overlay {
  position: fixed;
  top: 0; left: 0;
  width: 100%; height: 100%;
  background: rgba(0,0,0,0.5);
  z-index: 1000;
}

/* Ví dụ: badge góc */
.card {
  position: relative;
}
.badge {
  position: absolute;
  top: -8px; right: -8px;
  background: red;
  border-radius: 50%;
  width: 20px; height: 20px;
}

Bài tập thực hành

Bài tập 3.1: Style trang Profile từ Chương 2

Lấy file HTML trang profile đã tạo ở Chương 2, tạo file profile.css và style lại với:

  1. Font từ Google Fonts (Inter hoặc Roboto)
  2. Màu sắc theo theme nhất quán (dùng CSS Variables)
  3. Layout header với Flexbox (logo bên trái, nav bên phải)
  4. Card thông tin với padding, border-radius, box-shadow
  5. Bảng dự án được style đẹp (alternate row colors)
  6. Hover effects cho links và buttons
  7. Responsive: 1 cột trên mobile, 2 cột trên tablet+

Bài tập 3.2: Clone giao diện đơn giản

Xây dựng landing page đơn giản với layout:

/* Cấu trúc cần tạo */
<header>  ← navbar với logo + links (flexbox)
<section class="hero">  ← căn giữa, full height
<section class="features">  ← grid 3 cột
<footer>  ← flexbox, dark background

Yêu cầu: responsive (collapse sang 1 cột trên mobile), transitions khi hover, CSS variables cho colors.

Câu hỏi ôn bài

1. Nếu một phần tử có width: 200px; padding: 20px; border: 5px solid, với box-sizing: content-box (mặc định), phần tử đó thực sự rộng bao nhiêu pixel?

  • A. 200px
  • B. 240px
  • C. 250px
  • D. 260px

Đáp án: C — 250px = 200 (content) + 20×2 (padding trái/phải) + 5×2 (border trái/phải). Với border-box, tổng sẽ là 200px, content = 150px.

2. Để căn giữa một div cả theo chiều ngang và dọc trong viewport, cách nào dùng Flexbox là đúng?

  • A. margin: auto trên div con
  • B. display: flex; justify-content: center; align-items: center trên div cha
  • C. text-align: center; vertical-align: middle
  • D. position: absolute; top: 50%; left: 50%

Đáp án: B — Trên phần tử cha: display: flex; justify-content: center; align-items: center; min-height: 100vh;. Đây là cách căn giữa phổ biến và clean nhất với Flexbox.

3. Khi nào nên dùng CSS Grid thay vì Flexbox?

  • A. Luôn dùng Grid vì nó mạnh hơn
  • B. Khi cần layout hai chiều (hàng VÀ cột cùng lúc), như card grid hoặc page layout
  • C. Chỉ khi layout có nhiều hơn 3 cột
  • D. Grid và Flexbox hoàn toàn giống nhau

Đáp án: B — Grid tốt hơn khi cần kiểm soát cả hàng và cột (2D). Flexbox tốt hơn cho 1 chiều (hàng hoặc cột). Trong thực tế, thường dùng cả hai: Grid cho page layout, Flexbox cho component layout.

4. "Mobile First" trong responsive design nghĩa là gì?

  • A. Website chỉ dành cho mobile, không cần desktop
  • B. Viết CSS mặc định cho mobile, dùng min-width media query để thêm cho màn hình lớn hơn
  • C. Load CSS của mobile trước, CSS desktop sau
  • D. Test trên mobile trước, desktop sau

Đáp án: B — Mobile First nghĩa là CSS mặc định (không có media query) phục vụ mobile. Sau đó dùng @media (min-width: 768px), @media (min-width: 1024px) để thêm style cho tablet và desktop.

5. CSS Variable --color-primary được khai báo trong :root. Cách sử dụng đúng là?

  • A. color: --color-primary;
  • B. color: $color-primary;
  • C. color: var(--color-primary);
  • D. color: @color-primary;

Đáp án: C — CSS Variables dùng var(--tên-biến). Cú pháp $variable là của SCSS/Sass (preprocessor), @variable là của Less.
