JSX và Component

JSX là ngôn ngữ template của React — trông giống HTML nhưng thực ra là JavaScript. Trong chương này, bạn sẽ nắm vững cú pháp JSX, cách tạo Component, truyền dữ liệu qua Props, render có điều kiện, và xây dựng UI từ các "mảnh nhỏ" có thể tái sử dụng.

⏱ 60 phút đọc 💻 4 ví dụ thực hành 📝 5 câu hỏi ôn bài

1. JSX là gì? Tại sao React dùng JSX?

Trước khi React ra đời, để thêm một phần tử HTML vào trang bằng JavaScript, bạn phải viết: 

// JavaScript thuần — rất dài dòng
const h1 = document.createElement('h1');
h1.textContent = 'Xin chào!';
h1.className = 'title';
document.body.appendChild(h1);

React giải quyết sự dài dòng này bằng JSX (JavaScript XML) — một cú pháp mở rộng cho phép bạn viết "HTML" ngay bên trong JavaScript: 

// JSX — ngắn gọn và trực quan
const element = <h1 className="title">Xin chào!</h1>;

Trình duyệt không hiểu JSX trực tiếp. Babel (hoặc các trình biên dịch hiện đại như esbuild/SWC) sẽ chuyển đổi JSX thành lời gọi hàm JavaScript thuần: 

// Sau khi Babel biên dịch:
const element = React.createElement(
  'h1',
  { className: 'title' },
  'Xin chào!'
);
ℹ️ JSX không phải HTML

JSX trông rất giống HTML nhưng thực chất là JavaScript. Mọi thứ bạn viết trong JSX đều là biểu thức JavaScript, và có một số điểm khác biệt quan trọng bạn cần ghi nhớ.

2. JSX vs HTML — Các điểm khác biệt quan trọng

2.1. className thay vì class

Vì class là từ khóa dành riêng trong JavaScript, JSX dùng className: 

// HTML thông thường:
<div class="container"></div>

// JSX:
<div className="container"></div>

2.2. htmlFor thay vì for

Tương tự, for là từ khóa trong JavaScript (dùng cho vòng lặp), nên JSX dùng htmlFor:

// HTML:
<label for="email">Email:</label>
<input id="email" type="email" />

// JSX:
<label htmlFor="email">Email:</label>
<input id="email" type="email" />

2.3. Tất cả thẻ phải được đóng

Trong HTML, bạn có thể viết <img> hoặc <br> mà không cần đóng. Trong JSX, mọi thẻ đều phải được đóng — dùng self-closing với dấu />: 

// HTML — hợp lệ nhưng...
<img src="photo.jpg">
<br>
<input type="text">

// JSX — bắt buộc phải tự đóng
<img src="photo.jpg" />
<br />
<input type="text" />

2.4. Thuộc tính dùng camelCase

Các thuộc tính sự kiện và style đều được viết theo camelCase trong JSX:

HTMLJSXGiải thích
onclickonClickSự kiện click
onchangeonChangeThay đổi input
tabindextabIndexThứ tự tab
maxlengthmaxLengthGiới hạn ký tự
readonlyreadOnlyChỉ đọc
crossorigincrossOriginCORS

2.5. Style là object, không phải chuỗi

Trong HTML, style là chuỗi CSS. Trong JSX, style nhận vào một object JavaScript với các property viết theo camelCase: 

// HTML:
<p style="color: red; font-size: 16px; margin-top: 8px;">...</p>

// JSX — chú ý 2 cặp dấu ngoặc nhọn!
// {} ngoài: chèn biểu thức JS, {} trong: object literal
<p style={{ color: 'red', fontSize: '16px', marginTop: '8px' }}>...</p>

// Hoặc định nghĩa style trước:
const myStyle = {
  color: 'red',
  fontSize: '16px',      // font-size → fontSize
  marginTop: '8px',     // margin-top → marginTop
  backgroundColor: '#fff', // background-color → backgroundColor
};
<p style={myStyle}>...</p>

2.6. JSX phải có một root element duy nhất

Mỗi component chỉ có thể trả về một phần tử gốc. Nếu bạn cần trả về nhiều phần tử liền kề, dùng Fragment: 

// ❌ Lỗi — hai phần tử ngang hàng ở gốc
return (
  <h1>Tiêu đề</h1>
  <p>Nội dung</p>
);

// ✅ Đúng — bọc vào div
return (
  <div>
    <h1>Tiêu đề</h1>
    <p>Nội dung</p>
  </div>
);

// ✅ Tốt hơn — Fragment không thêm phần tử thừa vào DOM
return (
  <>
    <h1>Tiêu đề</h1>
    <p>Nội dung</p>
  </>
);

// Cú pháp đầy đủ của Fragment:
import { Fragment } from 'react';
return (
  <Fragment>
    <h1>Tiêu đề</h1>
    <p>Nội dung</p>
  </Fragment>
);

3. Biểu thức JavaScript trong JSX

Dùng dấu ngoặc nhọn {} để nhúng bất kỳ biểu thức JavaScript nào vào JSX: 

function Greeting() {
  const name = 'Minh';
  const age = 25;
  const greet = (n) => `Xin chào, ${n}!`;

  return (
    <div>
      {/* Biến */}
      <h1>{name}</h1>

      {/* Biểu thức tính toán */}
      <p>Năm sinh: {2024 - age}</p>

      {/* Gọi hàm */}
      <p>{greet(name)}</p>

      {/* Ternary operator */}
      <p>{age >= 18 ? 'Đã trưởng thành' : 'Chưa trưởng thành'}</p>

      {/* Short-circuit — chỉ render khi điều kiện đúng */}
      {age >= 18 && <span>Có thể mua rượu</span>}

      {/* Template literal */}
      <p className={`user-card ${age >= 18 ? 'adult' : 'minor'}`}>...</p>
    </div>
  );
}
⚠️ Không phải câu lệnh, chỉ là biểu thức

Bên trong {} chỉ có thể là biểu thức — thứ có giá trị trả về. Không thể dùng if/else, for, while, hay const/let/var bên trong JSX trực tiếp. Thay vào đó hãy dùng ternary, &&, hoặc gọi hàm.

4. Functional Component

Component là khối xây dựng cơ bản của React. Một Functional Component chỉ đơn giản là một hàm JavaScript trả về JSX.

4.1. Định nghĩa và quy ước đặt tên

// ✅ Đúng — PascalCase cho tên component
function WelcomeMessage() {
  return <h1>Chào mừng!</h1>;
}

// ✅ Arrow function cũng được
const WelcomeMessage = () => {
  return <h1>Chào mừng!</h1>;
};

// ✅ Implicit return với ngoặc đơn
const WelcomeMessage = () => (
  <h1>Chào mừng!</h1>
);

// ❌ Sai — tên bắt đầu bằng chữ thường → React coi là HTML tag
function welcomeMessage() { ... }

// Export component để dùng ở nơi khác
export default WelcomeMessage;

5. Props — Truyền dữ liệu giữa các Component

Props (viết tắt của properties) là cách truyền dữ liệu từ component cha xuống component con — giống như các tham số của một hàm.

5.1. Truyền và nhận Props

// Component cha truyền dữ liệu qua attributes
function App() {
  return (
    <div>
      <UserCard
        name="Nguyễn Minh"
        age={25}
        isAdmin={true}
        hobbies={['code', 'đọc sách']}
      />
    </div>
  );
}

// Cách 1: Nhận props như một object
function UserCard(props) {
  return (
    <div className="card">
      <h2>{props.name}</h2>
      <p>Tuổi: {props.age}</p>
      {props.isAdmin && <span className="badge">Admin</span>}
    </div>
  );
}

// Cách 2: Destructuring — phổ biến và gọn hơn
function UserCard({ name, age, isAdmin, hobbies }) {
  return (
    <div className="card">
      <h2>{name}</h2>
      <p>Tuổi: {age}</p>
      {isAdmin && <span className="badge">Admin</span>}
      <ul>
        {hobbies.map((h) => <li key={h}>{h}</li>)}
      </ul>
    </div>
  );
}

5.2. Default Props

// Gán giá trị mặc định ngay trong tham số
function Button({ label = 'Nhấn vào đây', color = 'blue', size = 'md' }) {
  return (
    <button
      className={`btn btn-${color} btn-${size}`}
      style={{ backgroundColor: color }}
    >
      {label}
    </button>
  );
}

// Sử dụng — không cần truyền label hay color
<Button />                        // Nhấn vào đây, xanh, vừa
<Button label="Đăng ký" />       // Đăng ký, xanh, vừa
<Button label="Xóa" color="red" /> // Xóa, đỏ, vừa

5.4. Children Prop — Truyền JSX vào trong Component

Prop đặc biệt children chứa bất kỳ nội dung nào đặt bên trong thẻ mở/đóng của component: 

// Component nhận children
function Card({ title, children }) {
  return (
    <div className="card">
      <div className="card-header"><h3>{title}</h3></div>
      <div className="card-body">
        {children}  {/* Nội dung được truyền vào */}
      </div>
    </div>
  );
}

// Sử dụng — nội dung bên trong sẽ là children
<Card title="Thông tin sản phẩm">
  <p>Giá: 500,000 VNĐ</p>
  <button>Thêm vào giỏ</button>
</Card>

// Một ví dụ hay — Layout component
function PageLayout({ children }) {
  return (
    <div className="page">
      <header><nav>...</nav></header>
      <main>{children}</main>
      <footer>© 2024</footer>
    </div>
  );
}

5.5. Props là Read-Only

🚫 Không bao giờ mutate Props

Props là bất biến (immutable) — component con không được phép thay đổi props nhận từ cha. Đây là quy tắc cơ bản của React. Nếu bạn cần thay đổi dữ liệu, hãy dùng State (học ở chương tiếp theo).

function UserCard({ name }) {
  // ❌ Không bao giờ làm thế này!
  name = 'Tên khác';

  // ✅ Nếu cần biến đổi, tạo biến cục bộ mới
  const displayName = name.toUpperCase();

  return <h2>{displayName}</h2>;
}

6. Conditional Rendering — Render có điều kiện

6.1. if/else trước return

function UserStatus({ isLoggedIn, username }) {
  // Logic điều kiện TRƯỚC khi return
  if (!isLoggedIn) {
    return (
      <div>
        <p>Bạn chưa đăng nhập.</p>
        <a href="/login">Đăng nhập ngay</a>
      </div>
    );
  }

  return <p>Xin chào, {username}!</p>;
}

6.2. Ternary Operator trong JSX

function LoginButton({ isLoggedIn, onLogin, onLogout }) {
  return (
    <div>
      {isLoggedIn
        ? <button onClick={onLogout}>Đăng xuất</button>
        : <button onClick={onLogin}>Đăng nhập</button>
      }
    </div>
  );
}

6.3. Short-circuit &&

function Notification({ count, message }) {
  return (
    <div>
      {/* Chỉ render khi count > 0 */}
      {count > 0 && <span className="badge">{count}</span>}

      {/* Chú ý: tránh dùng số 0 với && */}
      {/* ❌ Sẽ render số 0 ra màn hình */}
      {count && <span>{count}</span>}

      {/* ✅ Chuyển sang boolean trước */}
      {count > 0 && <span>{count}</span>}
      {!!message && <p>{message}</p>}
    </div>
  );
}

6.4. Nullish check với Optional Chaining

function UserAvatar({ user }) {
  return (
    <div>
      {/* Chỉ render ảnh nếu user và user.avatar tồn tại */}
      {user?.avatar && <img src={user.avatar} alt={user?.name ?? 'Ẩn danh'} />}

      {/* Hiện tên hoặc 'Khách' nếu không có tên */}
      <span>{user?.name ?? 'Khách'}</span>
    </div>
  );
}

7. Render Danh sách với Array.map()

7.1. Cách render một mảng

function FruitList() {
  const fruits = [
    { id: 1, name: 'Táo', color: 'đỏ' },
    { id: 2, name: 'Chuối', color: 'vàng' },
    { id: 3, name: 'Cam', color: 'cam' },
  ];

  return (
    <ul>
      {fruits.map((fruit) => (
        {/* key là bắt buộc! */}
        <li key={fruit.id}>
          {fruit.name} — màu {fruit.color}
        </li>
      ))}
    </ul>
  );
}

7.2. Tại sao cần prop key?

Khi React render một danh sách, nó cần biết phần tử nào thay đổi, được thêm vào, hay bị xóa để cập nhật DOM hiệu quả. Prop key cung cấp thông tin này.

7.3. Quy tắc dùng key — những lỗi thường gặp

// ❌ Dùng index làm key — nguy hiểm khi list thay đổi thứ tự
{items.map((item, index) => (
  <Item key={index} data={item} />
))}

// ❌ Key không unique
{users.map((user) => (
  <User key={user.name} />  // Có thể trùng tên!
))}

// ✅ Dùng ID unique từ database
{users.map((user) => (
  <User key={user.id} data={user} />
))}

// ✅ Nếu không có ID — dùng crypto.randomUUID() một lần khi tạo data
const items = rawData.map(item => ({
  ...item,
  id: crypto.randomUUID()
}));
⚠️ Key chỉ cần unique trong cùng một danh sách

Key không cần phải unique toàn cục. Hai list khác nhau có thể dùng cùng key mà không có vấn đề gì. Key cũng không được truyền vào component con như prop — nếu bạn cần ID, truyền thêm prop id riêng.

Bài tập — Trang Danh Sách Sản Phẩm

Xây dựng một trang danh sách sản phẩm với ba component: ProductList, ProductCard, và Badge.

Yêu cầu:

  • Hiển thị danh sách sản phẩm với tên, giá, và trạng thái
  • Badge hiển thị nhãn "Sale" hoặc "Mới" tùy thuộc vào thuộc tính sản phẩm
  • Render có điều kiện: ẩn sản phẩm hết hàng
src/components/Badge.jsx 
// Badge.jsx — component tái sử dụng
function Badge({ type = 'info', children }) {
  const colorMap = {
    sale: '#e06c75',
    new: '#98c379',
    info: '#56b6c2',
    hot: '#e5c07b',
  };

  const style = {
    display: 'inline-block',
    background: colorMap[type] ?? colorMap.info,
    color: '#fff',
    padding: '2px 10px',
    borderRadius: '12px',
    fontSize: '0.75rem',
    fontWeight: '700',
    marginRight: '6px',
  };

  return <span style={style}>{children}</span>;
}

export default Badge;
src/components/ProductCard.jsx 
import Badge from './Badge';

function ProductCard({ product }) {
  const { name, price, originalPrice, isNew, isSale, stock, image } = product;

  // Không render sản phẩm hết hàng
  if (stock === 0) return null;

  const formatPrice = (amount) =>
    new Intl.NumberFormat('vi-VN', {
      style: 'currency',
      currency: 'VND'
    }).format(amount);

  return (
    <div style={{
      border: '1px solid #3e4451',
      borderRadius: '8px',
      padding: '20px',
      background: '#282c34',
    }}>
      {/* Ảnh sản phẩm */}
      {image && <img src={image} alt={name} style={{ width: '100%', borderRadius: '4px', marginBottom: '12px' }} />}

      {/* Badges */}
      <div style={{ marginBottom: '8px' }}>
        {isNew && <Badge type="new">Mới</Badge>}
        {isSale && <Badge type="sale">Sale</Badge>}
        {stock <= 5 && <Badge type="hot">Sắp hết</Badge>}
      </div>

      {/* Tên sản phẩm */}
      <h3 style={{ color: '#e6e6e6', margin: '0 0 8px', fontSize: '1rem' }}>
        {name}
      </h3>

      {/* Giá */}
      <div>
        <span style={{ color: '#61dafb', fontWeight: '700', fontSize: '1.1rem' }}>
          {formatPrice(price)}
        </span>
        {isSale && originalPrice && (
          <span style={{ color: '#5c6370', textDecoration: 'line-through', marginLeft: '8px', fontSize: '0.85rem' }}>
            {formatPrice(originalPrice)}
          </span>
        )}
      </div>

      {/* Tồn kho */}
      <p style={{ color: '#5c6370', fontSize: '0.8rem', marginTop: '8px' }}>
        Còn {stock} sản phẩm
      </p>

      <button style={{
        width: '100%',
        marginTop: '16px',
        padding: '10px',
        background: '#61dafb',
        color: '#282c34',
        border: 'none',
        borderRadius: '6px',
        fontWeight: '700',
        cursor: 'pointer',
      }}>
        Thêm vào giỏ hàng
      </button>
    </div>
  );
}

export default ProductCard;

    image: null,
  },
];

function ProductList() {
  const availableProducts = PRODUCTS.filter(p => p.stock > 0);

  return (
    <div style={{ maxWidth: '900px', margin: '0 auto', padding: '40px 20px' }}>
      <h1 style={{ color: '#e6e6e6', marginBottom: '8px' }}>Danh sách sản phẩm</h1>
      <p style={{ color: '#abb2bf', marginBottom: '32px' }}>
        Hiển thị {availableProducts.length}/{PRODUCTS.length} sản phẩm (hết hàng đã ẩn)
      </p>

      {availableProducts.length === 0 ? (
        <div style={{ textAlign: 'center', padding: '80px', color: '#5c6370' }}>
          <p>Không có sản phẩm nào.</p>
        </div>
      ) : (
        <div style={{
          display: 'grid',
          gridTemplateColumns: 'repeat(auto-fill, minmax(240px, 1fr))',
          gap: '20px',
        }}>
          {availableProducts.map((product) => (
            <ProductCard key={product.id} product={product} />
          ))}
        </div>
      )}
    </div>
  );
}

export default ProductList;
