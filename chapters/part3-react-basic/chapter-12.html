useEffect và Vòng đời Component

useEffect là hook để xử lý các "side effects" — những việc nằm ngoài việc render UI thuần túy: gọi API, subscriptions, thao tác DOM, timers. Hiểu useEffect đúng cách là kỹ năng quan trọng nhất để tránh bug trong React.

12.1 Vòng đời Component (Component Lifecycle)

12.2 useEffect cơ bản

import { useState, useEffect } from 'react';

function Timer() {
  const [seconds, setSeconds] = useState(0);

  // useEffect nhận 2 tham số:
  // 1. Effect function (callback)
  // 2. Dependency array (tùy chọn)
  useEffect(() => {
    // Code này chạy SAU mỗi lần render
    console.log("Component đã render, seconds:", seconds);
  });

  return <p>Giây: {seconds}</p>;
}

12.3 Dependency Array — Kiểm soát khi nào Effect chạy

// 1. Không có dependency array → chạy sau MỌI render
useEffect(() => {
  console.log("Chạy sau mỗi render");
});

// 2. Mảng rỗng [] → chỉ chạy một lần sau render ĐẦU TIÊN (mount)
useEffect(() => {
  console.log("Chạy 1 lần khi mount");
  // Dùng để: fetch dữ liệu ban đầu, setup subscription, init library
}, []);

// 3. Có dependencies → chạy khi dependencies thay đổi
useEffect(() => {
  console.log("userId thay đổi:", userId);
  // Fetch dữ liệu khi userId thay đổi
}, [userId]); // Chỉ chạy khi userId thay đổi

// 4. Nhiều dependencies
useEffect(() => {
  // Chạy khi page hoặc pageSize thay đổi
}, [page, pageSize]);
⚠️ Exhaustive deps — Luôn khai báo đủ dependencies

Nếu dùng biến nào trong effect, phải khai báo trong dependency array. Bỏ qua → stale closure bug. ESLint với rule react-hooks/exhaustive-deps sẽ cảnh báo. Đừng ignore cảnh báo đó!

12.4 Cleanup Function

Effect có thể trả về một hàm — đây là "cleanup function". Nó chạy khi component unmount hoặc trước khi effect chạy lại.

// Cleanup timer
function Timer() {
  const [count, setCount] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setCount(prev => prev + 1);
    }, 1000);

    // Cleanup: xóa interval khi unmount
    return () => {
      clearInterval(interval);
      console.log("Timer đã dọn dẹp");
    };
  }, []); // Chỉ chạy 1 lần khi mount

  return <p>Đếm: {count}</p>;
}

// Cleanup event listener
useEffect(() => {
  const handleResize = () => {
    setWindowWidth(window.innerWidth);
  };

  window.addEventListener('resize', handleResize);

  return () => {
    window.removeEventListener('resize', handleResize);
  };
}, []);

// Cleanup WebSocket
useEffect(() => {
  const ws = new WebSocket('wss://example.com');
  ws.onmessage = (event) => setMessages(prev => [...prev, event.data]);

  return () => {
    ws.close();
  };
}, []);

12.5 Fetch Data với useEffect

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    let cancelled = false; // Flag để tránh set state sau unmount

    async function fetchUser() {
      try {
        setLoading(true);
        setError(null);
        const response = await fetch(`/api/users/${userId}`);
        if (!response.ok) throw new Error('Không tìm thấy người dùng');
        const data = await response.json();
        if (!cancelled) setUser(data); // Chỉ set state nếu chưa unmount
      } catch (err) {
        if (!cancelled) setError(err.message);
      } finally {
        if (!cancelled) setLoading(false);
      }
    }

    fetchUser();

    return () => {
      cancelled = true; // Hủy khi component unmount hoặc userId thay đổi
    };
  }, [userId]); // Re-fetch khi userId thay đổi

  if (loading) return <p>Đang tải...</p>;
  if (error) return <p className="error">{error}</p>;
  if (!user) return null;

  return (
    <div>
      <h2>{user.name}</h2>
      <p>{user.email}</p>
    </div>
  );
}

12.6 useEffect và Debounce

// Debounce search — gọi API sau khi user ngừng gõ 500ms
function SearchBox() {
  const [query, setQuery] = useState('');
  const [results, setResults] = useState([]);
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    if (!query.trim()) {
      setResults([]);
      return;
    }

    setLoading(true);

    // Đặt timer 500ms
    const timer = setTimeout(async () => {
      try {
        const res = await fetch(`/api/search?q=${encodeURIComponent(query)}`);
        const data = await res.json();
        setResults(data);
      } catch (err) {
        console.error(err);
      } finally {
        setLoading(false);
      }
    }, 500);

    // Cleanup: hủy timer nếu query thay đổi trước 500ms
    return () => clearTimeout(timer);
  }, [query]); // Re-run khi query thay đổi

  return (
    <div>
      <input
        value={query}
        onChange={e => setQuery(e.target.value)}
        placeholder="Tìm kiếm..."
      />
      {loading && <p>Đang tìm...</p>}
      <ul>
        {results.map(r => (
          <li key={r.id}>{r.name}</li>
        ))}
      </ul>
    </div>
  );
}

12.7 Các useEffect thường dùng

// Cập nhật document title
useEffect(() => {
  document.title = `${count} thông báo mới`;
}, [count]);

// Sync với localStorage
useEffect(() => {
  localStorage.setItem('theme', theme);
}, [theme]);

// Đọc từ localStorage khi mount
const [theme, setTheme] = useState(() => {
  // Lazy initial state — chạy 1 lần
  return localStorage.getItem('theme') || 'light';
});

// Scroll to top khi navigate
useEffect(() => {
  window.scrollTo(0, 0);
}, [pathname]);

// Lock body scroll khi modal mở
useEffect(() => {
  if (isModalOpen) {
    document.body.style.overflow = 'hidden';
  }
  return () => {
    document.body.style.overflow = 'unset';
  };
}, [isModalOpen]);

Câu hỏi ôn bài

1. useEffect với dependency array rỗng [] sẽ chạy khi nào?

  • A. Sau mỗi lần render
  • B. Chỉ một lần sau lần render đầu tiên (mount)
  • C. Không bao giờ chạy
  • D. Chỉ chạy khi component unmount

Đáp án: B — [] nghĩa là không có dependency nào → effect không cần chạy lại khi dependencies thay đổi (vì không có) → chỉ chạy một lần sau mount.

2. Cleanup function trong useEffect là gì và khi nào nó chạy?

  • A. Một hàm xóa state khi component re-render
  • B. Hàm được return từ effect, chạy khi component unmount hoặc trước khi effect chạy lại
  • C. Hàm tự động xóa event listeners
  • D. Hàm chạy trước khi effect bắt đầu

Đáp án: B — Cleanup chạy: (1) Khi component unmount, (2) Trước khi effect chạy lại (do deps thay đổi). Dùng để: clearInterval, removeEventListener, hủy fetch, đóng WebSocket.

3. Tại sao cần dùng flag cancelled khi fetch dữ liệu trong useEffect?

  • A. Để cancel request HTTP
  • B. Để tránh set state trên component đã unmount (memory leak và bug)
  • C. Để tăng tốc độ fetch
  • D. Không cần thiết, React tự xử lý

Đáp án: B — Nếu component unmount trong khi fetch đang chạy, fetch vẫn hoàn thành và cố set state → React cảnh báo "Can't perform a React state update on an unmounted component". Flag cancelled ngăn điều này.

4. Kỹ thuật debounce trong useEffect hoạt động như thế nào?

  • A. Gọi API ngay lập tức mỗi lần user gõ
  • B. Dùng setTimeout và clearTimeout trong cleanup: chờ user ngừng gõ một khoảng thời gian rồi mới gọi API
  • C. Chặn input của user
  • D. Cache kết quả API

Đáp án: B — setTimeout tạo timer khi query thay đổi. Cleanup (return) hủy timer nếu query thay đổi tiếp. Kết quả: API chỉ được gọi sau khi user ngừng gõ N milliseconds.

5. Điều gì xảy ra nếu bạn bỏ userId ra khỏi dependency array khi dùng nó trong effect?

  • A. Effect vẫn chạy đúng
  • B. Stale closure bug: effect luôn dùng giá trị userId cũ khi mount
  • C. React tự động thêm userId vào deps
  • D. Effect không bao giờ chạy

Đáp án: B — Đây là "stale closure" bug. Effect được tạo lần đầu với userId=1. Khi userId thay đổi sang 2, effect không chạy lại (vì deps rỗng) nhưng closure vẫn "nhớ" userId=1.
