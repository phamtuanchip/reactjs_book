React Router — Điều hướng trang

React Router là thư viện routing tiêu chuẩn cho React SPA. Nó cho phép tạo nhiều "trang" trong ứng dụng SPA mà không cần tải lại trình duyệt, tạo trải nghiệm người dùng mượt mà như app native.

14.1 Routing trong SPA hoạt động như thế nào?

Trong SPA, chỉ có một file HTML. React Router lắng nghe thay đổi URL (dùng History API của trình duyệt) và render component phù hợp.

14.3 Link, NavLink và useNavigate

import { Link, NavLink, useNavigate } from 'react-router-dom';

// Link — điều hướng không reload trang
function Navbar() {
  return (
    <nav>
      <Link to="/">Trang chủ</Link>
      <Link to="/products">Sản phẩm</Link>
      <Link to="/about">Về chúng tôi</Link>
    </nav>
  );
}

// NavLink — tự động thêm class "active" khi URL khớp
function Navbar() {
  return (
    <nav>
      <NavLink
        to="/"
        className={({ isActive }) => isActive ? 'nav-link active' : 'nav-link'}
        end {/* Chỉ active khi URL chính xác là "/" */}
      >
        Trang chủ
      </NavLink>
      <NavLink to="/products" className={({ isActive }) =>
        isActive ? 'nav-link active' : 'nav-link'
      }>
        Sản phẩm
      </NavLink>
    </nav>
  );
}

// useNavigate — điều hướng bằng JavaScript (không phải click)
function LoginForm() {
  const navigate = useNavigate();

  const handleSubmit = async (e) => {
    e.preventDefault();
    const success = await login(email, password);
    if (success) {
      navigate('/dashboard');                 // Đến trang dashboard
      navigate('/dashboard', { replace: true }); // Thay thế (không thể back)
      navigate(-1);                           // Back
      navigate(-2);                           // Back 2 lần
      navigate(1);                            // Forward
    }
  };
}

14.4 Route Parameters và useParams

// Định nghĩa route với parameter
<Route path="products/:id" element={<ProductDetail />} />
<Route path="users/:userId/posts/:postId" element={<Post />} />

// Đọc parameter trong component
import { useParams } from 'react-router-dom';

function ProductDetail() {
  const { id } = useParams(); // "42" (luôn là string!)

  const [product, setProduct] = useState(null);

  useEffect(() => {
    fetch(`/api/products/${id}`)
      .then(r => r.json())
      .then(setProduct);
  }, [id]);

  return <div>...</div>;
}

// Query string — useSearchParams
import { useSearchParams } from 'react-router-dom';

function ProductList() {
  const [searchParams, setSearchParams] = useSearchParams();
  const page = Number(searchParams.get('page')) || 1;
  const category = searchParams.get('category') || 'all';

  const handlePageChange = (newPage) => {
    setSearchParams({ page: newPage, category });
  };

  // URL: /products?page=2&category=tech
}

14.6 Protected Routes

Protected routes chỉ cho phép người dùng đã đăng nhập truy cập:

// ProtectedRoute component
import { Navigate, useLocation } from 'react-router-dom';

function ProtectedRoute({ children }) {
  const { isAuthenticated } = useAuth(); // Custom hook lấy auth state
  const location = useLocation();

  if (!isAuthenticated) {
    // Chuyển đến login, lưu lại URL hiện tại để redirect sau khi login
    return <Navigate to="/login" state={{ from: location }} replace />;
  }

  return children;
}

// Dùng trong Routes
<Route
  path="dashboard"
  element={
    <ProtectedRoute>
      <Dashboard />
    </ProtectedRoute>
  }
/>

// Login form — redirect về trang cũ sau khi login
function Login() {
  const navigate = useNavigate();
  const location = useLocation();
  const from = location.state?.from?.pathname || '/';

  const handleLogin = async () => {
    await login(email, password);
    navigate(from, { replace: true }); // Về trang đã định vào
  };
}

Câu hỏi ôn bài

1. Sự khác biệt giữa <Link> và thẻ <a> thông thường trong React Router?

  • A. Không có sự khác biệt
  • B. <Link> điều hướng không reload trang (SPA navigation), <a> reload toàn bộ trang
  • C. <Link> chỉ dùng được trong React
  • D. <a> nhanh hơn <Link>

Đáp án: B — <Link> dùng History API để thay đổi URL mà không gửi request mới → SPA không reload. <a href> gửi request mới đến server → trang reload.

2. useParams() trả về giá trị kiểu dữ liệu gì?

  • A. Number
  • B. String (luôn là string)
  • C. Tùy thuộc vào giá trị trong URL
  • D. Object với kiểu mixed

Đáp án: B — URL params luôn là string. Nếu cần number, phải convert: const id = Number(params.id) hoặc parseInt(params.id, 10).

3. <Outlet /> trong React Router dùng để làm gì?

  • A. Thoát khỏi trang hiện tại
  • B. Là nơi render child routes trong nested routing
  • C. Hiển thị loading indicator
  • D. Kết thúc route definition

Đáp án: B — <Outlet /> là placeholder cho child routes. Khi URL match child route, component đó render tại vị trí của <Outlet /> trong layout cha.

4. Trong protected route, tại sao nên dùng <Navigate replace /> thay vì không có replace?

  • A. Để trang nhanh hơn
  • B. Để người dùng không thể nhấn "Back" quay lại trang yêu cầu đăng nhập
  • C. Bắt buộc phải có replace
  • D. Không có sự khác biệt

Đáp án: B — Không có replace: user vào /dashboard → redirect /login → nhấn Back → lại vào /dashboard → lại redirect /login (loop). Với replace: /login thay thế /dashboard trong history, Back sẽ về trang trước /dashboard.

5. Route path="*" có ý nghĩa gì?

  • A. Match tất cả routes (luôn render)
  • B. Wildcard — match bất kỳ URL nào không được match bởi routes khác (dùng cho 404)
  • C. Route không có URL
  • D. Match URL có dấu * trong đó

Đáp án: B — path="*" là catch-all: nếu không có route nào match URL hiện tại → route này được render. Đặt cuối cùng trong Routes list để làm trang 404.
