Styling trong React

Giao diện đẹp không tự nhiên mà có — cần công cụ đúng và chiến lược phù hợp. Chương này khám phá đầy đủ các cách tạo kiểu trong React: từ CSS thuần túy, CSS Modules, Styled Components, cho đến Tailwind CSS — công cụ đang thống trị các dự án React hiện đại.

⏱ ~60 phút đọc 🎯 Beginner → Intermediate 💻 5 ví dụ code

1. Các cách Styling trong React — Tổng quan

Khác với HTML tĩnh, React cho phép bạn lựa chọn nhiều cách tiếp cận styling khác nhau tùy theo quy mô dự án và sở thích của nhóm. Không có một "đáp án đúng" duy nhất — mỗi phương pháp có ưu và nhược điểm riêng.

2. Plain CSS — Cách cổ điển

Cách đơn giản nhất: tạo file .css và import vào component. CSS được apply globally — mọi component đều có thể bị ảnh hưởng.

Button.css
/* CSS toàn cục — bất kỳ đâu trong app cũng áp dụng */
.button {
  background-color: #61dafb;
  color: #282c34;
  padding: 10px 20px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  font-weight: 600;
}

.button:hover {
  background-color: #21a1c4;
}
Button.jsx
import './Button.css'; // Import CSS — không cần gán vào biến

function Button({ children, onClick }) {
  return (
    <button className="button" onClick={onClick}>
      {children}
    </button>
  );
}
⚠️ Vấn đề của Plain CSS

Nếu hai component khác nhau đều có class .button, chúng sẽ ghi đè lên nhau tuỳ thuộc vào thứ tự import. Đây là lý do CSS Modules ra đời.

3. CSS Modules — Giải pháp scope local

CSS Modules giải quyết vấn đề xung đột tên class bằng cách tự động tạo tên class unique cho mỗi component. Được hỗ trợ sẵn trong Vite và Create React App.

3.1 Tạo file CSS Module

Quy ước đặt tên: TênComponent.module.css — phần .module là bắt buộc để Vite nhận biết đây là CSS Module.

Button.module.css
/* Đây là CSS Module — class names sẽ được hash tự động */
.button {
  background-color: #61dafb;
  color: #282c34;
  padding: 10px 20px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  font-weight: 600;
  transition: background-color 0.2s;
}

.button:hover {
  background-color: #21a1c4;
}

.primary {
  background-color: #61dafb;
}

.secondary {
  background-color: transparent;
  border: 2px solid #61dafb;
  color: #61dafb;
}

.large {
  padding: 14px 28px;
  font-size: 1.1rem;
}

.small {
  padding: 6px 14px;
  font-size: 0.85rem;
}

3.2 Import và sử dụng

Button.jsx
import styles from './Button.module.css';
// styles là object: { button: 'Button_button__xKz9m', primary: '...', ... }

function Button({ children, variant = 'primary', size = 'medium', onClick }) {
  return (
    <button
      className={`${styles.button} ${styles[variant]} ${size !== 'medium' ? styles[size] : ''}`}
      onClick={onClick}
    >
      {children}
    </button>
  );
}

export default Button;

// Sử dụng:
// <Button variant="primary" size="large">Xác nhận</Button>
// <Button variant="secondary">Huỷ</Button>

3.3 Combining classes với thư viện classnames

Khi cần kết hợp nhiều class có điều kiện, template literal sẽ trở nên lộn xộn. Thư viện classnames (hoặc clsx) giúp code gọn hơn nhiều.

Terminal
npm install classnames
# hoặc clsx (nhẹ hơn)
npm install clsx
Button.jsx — dùng clsx
import clsx from 'clsx';
import styles from './Button.module.css';

function Button({ children, variant = 'primary', size, disabled, onClick }) {
  return (
    <button
      className={clsx(
        styles.button,
        styles[variant],           // 'primary' | 'secondary'
        size && styles[size],      // 'large' | 'small' | falsy
        disabled && styles.disabled
      )}
      disabled={disabled}
      onClick={onClick}
    >
      {children}
    </button>
  );
}
✅ Tại sao CSS Modules tốt?

Tên class được hash tự động (ví dụ: Button_button__xKz9m), đảm bảo không bao giờ xung đột dù 100 component cùng dùng tên .button. Bạn viết CSS thuần, không phải học syntax mới — chỉ thêm .module vào tên file.

4. Styled Components — CSS-in-JS

Styled Components cho phép bạn viết CSS bên trong file JavaScript, gắn liền với component. CSS sẽ tự động scoped và hỗ trợ dynamic styling dựa trên props.

4.1 Cài đặt

Terminal
npm install styled-components

4.2 Tạo styled component cơ bản

Button.jsx
import styled from 'styled-components';

// Tạo component Button từ thẻ <button>
// Dùng template literal (backtick) để viết CSS
const StyledButton = styled.button`
  background-color: #61dafb;
  color: #282c34;
  padding: 10px 20px;
  border: none;
  border-radius: 6px;
  cursor: pointer;
  font-weight: 600;
  font-size: 1rem;
  transition: all 0.2s;

  &:hover {
    background-color: #21a1c4;
    transform: translateY(-1px);
  }

  &:active {
    transform: translateY(0);
  }
`;

function Button({ children, onClick }) {
  return (
    <StyledButton onClick={onClick}>
      {children}
    </StyledButton>
  );
}

4.3 Dynamic styling với Props

Đây là điểm mạnh nhất của Styled Components: thay đổi style dựa trên props một cách tự nhiên, không cần thêm class hay logic phức tạp.

Button.jsx — dynamic với props
import styled from 'styled-components';

const Button = styled.button`
  padding: ${props => props.size === 'large' ? '14px 28px' : '10px 20px'};
  font-size: ${props => props.size === 'large' ? '1.1rem' : '1rem'};
  border-radius: 6px;
  border: 2px solid #61dafb;
  cursor: pointer;
  font-weight: 600;
  transition: all 0.2s;

  /* Conditional styling dựa trên prop 'variant' */
  background-color: ${props => props.variant === 'primary' ? '#61dafb' : 'transparent'};
  color: ${props => props.variant === 'primary' ? '#282c34' : '#61dafb'};

  /* Disabled state */
  opacity: ${props => props.disabled ? '0.5' : '1'};
  cursor: ${props => props.disabled ? 'not-allowed' : 'pointer'};

  &:hover:not(:disabled) {
    transform: translateY(-2px);
    box-shadow: 0 4px 12px rgba(97, 218, 251, 0.3);
  }
`;

// Sử dụng:
// <Button variant="primary" size="large">Đăng nhập</Button>
// <Button variant="outline">Huỷ</Button>
// <Button disabled>Đang xử lý...</Button>

5.6 Utility cn() với clsx và tailwind-merge

Trong React, bạn thường cần kết hợp class Tailwind có điều kiện. Vấn đề là Tailwind có thể có class conflict (ví dụ: p-4 và p-6). Combo clsx + tailwind-merge giải quyết vấn đề này.

Terminal
npm install clsx tailwind-merge
lib/utils.ts
import { clsx, ClassValue } from 'clsx';
import { twMerge } from 'tailwind-merge';

// Hàm cn() — chuẩn trong mọi dự án dùng Tailwind + Shadcn
export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs));
}
Button.jsx — dùng cn()
import { cn } from '../lib/utils';

function Button({ children, className, variant = 'primary', size = 'md', disabled }) {
  return (
    <button
      className={cn(
        // Base classes
        'inline-flex items-center justify-center rounded-md font-medium transition-colors',
        'focus:outline-none focus:ring-2 focus:ring-offset-2',
        // Variant classes
        variant === 'primary' && 'bg-blue-500 text-white hover:bg-blue-600 focus:ring-blue-500',
        variant === 'outline' && 'border border-blue-500 text-blue-500 hover:bg-blue-50',
        variant === 'ghost'   && 'text-gray-700 hover:bg-gray-100',
        // Size classes
        size === 'sm' && 'px-3 py-1.5 text-sm',
        size === 'md' && 'px-4 py-2 text-sm',
        size === 'lg' && 'px-6 py-3 text-base',
        // Disabled
        disabled && 'opacity-50 cursor-not-allowed pointer-events-none',
        // Custom classes từ bên ngoài (override nếu cần)
        className
      )}
      disabled={disabled}
    >
      {children}
    </button>
  );
}
💡 Tại sao Tailwind phổ biến trong React?

Tailwind CSS bùng nổ trong cộng đồng React vì nhiều lý do: (1) Không cần đặt tên — một trong những việc khó nhất trong lập trình; (2) Colocation — style và markup ở cùng một chỗ; (3) Bundle size nhỏ — Tailwind chỉ include CSS của class bạn dùng; (4) Design system sẵn có — hệ thống spacing, color, typography nhất quán ngay từ đầu; (5) Ecosystem mạnh — Shadcn/ui, Headless UI, Radix UI đều built on Tailwind.

6. Inline Styles — Khi nào dùng?

Inline styles trong React nhận một object JavaScript thay vì string CSS. Tên property dùng camelCase: backgroundColor thay vì background-color.

Inline styles
// Style object — tên property là camelCase
const boxStyle = {
  backgroundColor: '#282c34',
  padding: '16px',
  borderRadius: '8px',
  boxShadow: '0 4px 20px rgba(0,0,0,0.3)',
};

<div style={boxStyle}>Nội dung</div>

// Inline trực tiếp (ít dùng cho nhiều property)
<div style={{ color: 'red', fontSize: '1.2rem' }>Text</div>

// ✅ Dùng inline khi: giá trị dynamic không thể biết trước
function ProgressBar({ percent }) {
  return (
    <div style={{ width: `${percent}%` }} className="bg-blue-500 h-2 rounded" />
  );
}

// ✅ Dùng inline cho CSS custom properties (variables)
<div style={{ '--rotation': `${rotation}deg` }} className="rotate-[var(--rotation)]" />
⚠️ Khi nào KHÔNG dùng inline styles?

Tránh dùng inline styles cho mọi thứ — chúng không hỗ trợ pseudo-classes (:hover), media queries, và khó bảo trì. Chỉ dùng khi giá trị thực sự cần tính toán động tại runtime.

  const [input, setInput] = useState('');
  const [filter, setFilter] = useState('all');

  const addTodo = (e) => {
    e.preventDefault();
    if (!input.trim()) return;
    setTodos(prev => [...prev, { id: Date.now(), text: input.trim(), done: false }]);
    setInput('');
  };

  const toggleTodo = (id) =>
    setTodos(prev => prev.map(t => t.id === id ? { ...t, done: !t.done } : t));

  const deleteTodo = (id) =>
    setTodos(prev => prev.filter(t => t.id !== id));

  const filtered = todos.filter(t => {
    if (filter === 'active') return !t.done;
    if (filter === 'completed') return t.done;
    return true;
  });

  const remaining = todos.filter(t => !t.done).length;

  return (
    <div className="min-h-screen bg-gray-950 flex items-start justify-center pt-16 px-4">
      <div className="w-full max-w-md">

        {/* Header */}
        <div className="mb-8 text-center">
          <h1 className="text-4xl font-bold text-cyan-400 tracking-tight">
            Todo App
          </h1>
          <p className="text-gray-500 mt-2 text-sm">
            {remaining} việc chưa hoàn thành
          </p>
        </div>

        {/* Input Form */}
        <form onSubmit={addTodo} className="flex gap-2 mb-4">
          <input
            value={input}
            onChange={e => setInput(e.target.value)}
            placeholder="Thêm việc cần làm..."
            className="flex-1 bg-gray-800 text-white border border-gray-700
              rounded-lg px-4 py-2.5 text-sm placeholder-gray-500
              focus:outline-none focus:border-cyan-500 focus:ring-1 focus:ring-cyan-500
              transition-colors"
          />
          <button
            type="submit"
            className="bg-cyan-500 hover:bg-cyan-400 text-gray-900 font-semibold
              px-4 py-2.5 rounded-lg text-sm transition-colors
              active:scale-95"
          >
            Thêm
          </button>
        </form>

        {/* Filter Tabs */}
        <div className="flex gap-1 mb-4 bg-gray-800 p-1 rounded-lg">
          {FILTERS.map(f => (
            <button
              key={f}
              onClick={() => setFilter(f)}
              className={cn(
                'flex-1 py-1.5 rounded-md text-xs font-medium capitalize transition-all',
                filter === f
                  ? 'bg-cyan-500 text-gray-900'
                  : 'text-gray-400 hover:text-white'
              )}
            >
              {f === 'all' ? 'Tất cả' : f === 'active' ? 'Chưa xong' : 'Đã xong'}
            </button>
          ))}
        </div>

        {/* Todo List */}
        <div className="space-y-2">
          {filtered.length === 0 && (
            <p className="text-center text-gray-600 py-8 text-sm">
              Không có việc nào
            </p>
          )}
          {filtered.map(todo => (
            <div
              key={todo.id}
              className="flex items-center gap-3 bg-gray-800 border border-gray-700
                rounded-lg px-4 py-3 group hover:border-gray-600 transition-colors"
            >
              {/* Checkbox */}
              <button
                onClick={() => toggleTodo(todo.id)}
                className={cn(
                  'w-5 h-5 rounded-full border-2 flex items-center justify-center flex-shrink-0 transition-all',
                  todo.done
                    ? 'bg-cyan-500 border-cyan-500'
                    : 'border-gray-600 hover:border-cyan-500'
                )}
              >
                {todo.done && <span className="text-gray-900 text-xs font-bold">✓</span>}
              </button>

              {/* Text */}
              <span className={cn(
                'flex-1 text-sm',
                todo.done ? 'line-through text-gray-600' : 'text-gray-200'
              )}>
                {todo.text}
              </span>

              {/* Delete */}
              <button
                onClick={() => deleteTodo(todo.id)}
                className="opacity-0 group-hover:opacity-100 text-gray-600
                  hover:text-red-400 transition-all text-lg leading-none"
              >
                ×
              </button>
            </div>
          ))}
        </div>

        {/* Footer */}
        {todos.some(t => t.done) && (
          <button
            onClick={() => setTodos(prev => prev.filter(t => !t.done))}
            className="mt-4 w-full text-xs text-gray-600 hover:text-red-400
              transition-colors py-2"
          >
            Xoá tất cả đã hoàn thành
          </button>
        )}

      </div>
    </div>
  );
}

export default TodoApp;
