# Chương 9 — Giới thiệu React

## Khởi tạo dự án

```bash
npm create vite@latest my-react-app -- --template react
cd my-react-app
npm install
npm run dev
```

## Cấu trúc dự án sau khi tạo

```
my-react-app/
├── src/
│   ├── App.jsx        ← Component gốc
│   ├── main.jsx       ← Entry point
│   └── index.css
├── index.html
├── vite.config.js
└── package.json
```
